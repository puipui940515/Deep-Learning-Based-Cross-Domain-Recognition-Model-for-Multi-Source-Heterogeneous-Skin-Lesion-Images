此資料夾是 UI 載入疾病預測模型的固定入口。`models/` 優先使用 NTFS 硬連結指向原始權重，因此不重複占用數 GB 空間；`model_registry.json` 記錄模型架構、輸入尺寸及來源。

更新模型清單：

```powershell
python ".\模型資產庫\sync_models.py"
```

只登錄能確認疾病類別順序、模型架構與推論前處理的模型。純部位模型、`last.pt`、快取檔與未保存可推論權重的實驗不放入疾病模型下拉選單。

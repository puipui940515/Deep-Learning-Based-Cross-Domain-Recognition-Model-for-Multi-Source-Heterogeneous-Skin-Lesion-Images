# 模型任務確認與評估指標說明

## 一、模型任務確認

### 1. 正式任務名稱

本專案目前執行的是：

> **HAM10000 單張皮膚鏡影像的七類、單標籤監督式分類。**

每次輸入一張 RGB 皮膚鏡影像，模型輸出 7 個 logits；經 softmax 後可轉為 7 類機率，最大機率所屬類別為模型預測。

「皮膚病偵測」是專案的通俗名稱，但目前模型的技術任務是**影像分類**，不是物件偵測。模型不會輸出病灶位置框，也不會產生病灶遮罩。

### 3. 本任務不代表什麼

- 不是「有病／沒病」或「良性／惡性」二分類。
- 不是病灶位置偵測或影像分割。
- 不是依人種或膚色分類；HAM10000 也不足以完成可靠的跨膚色公平性結論。
- 不是一般手機臨床照片分類；HAM10000 主體是皮膚鏡影像。
- 不是醫療器材或可獨立使用的臨床診斷系統。
- 目前結果是 validation 結果，不是封存 test 結果，也不是外部醫院驗證結果。

## 二、為什麼主指標是 Validation Balanced Accuracy

HAM10000 類別非常不平衡，`nv` 黑色素細胞痣占 6,705／10,015，約 67%。如果模型永遠預測 `nv`，一般 Accuracy 仍可接近 67%，但其餘六類完全無法辨識。

Balanced Accuracy 先分別計算每一類的 Recall，再對七類取相同權重的平均：

```text
每類 Recall = TP / (TP + FN)
Balanced Accuracy = 7 個類別 Recall 的平均
```

因此每個疾病類別的權重相同，不會由樣本最多的 `nv` 主導。七分類中「永遠猜同一類」的 majority baseline Balanced Accuracy 為 `1 / 7 = 0.1429`。

本次 v5 的 **Validation Balanced Accuracy = 0.5728 ± 0.0098**，意思是：在 validation split 上，先分別計算七種疾病被正確找回的比例，再平均後約為 **57.28%**。這不等同於「所有影像正確率 57.28%」，也不等同於臨床診斷敏感度 57.28%。

## 三、各項評估指標

### 1. Validation Balanced Accuracy（主指標，越高越好）

- 定義：各類 Recall 的算術平均。
- 用途：處理類別不平衡，作為模型選擇及 early stopping 的依據。
- v5：`0.5728 ± 0.0098`。
- 解讀：三個 seeds 的平均每類召回能力約 57.28%，且 seed 間變異約 0.98 個百分點。
- 注意：它不考慮預測錯誤時的信心，也不直接反映 Precision。

### 2. Validation Accuracy（輔助指標，越高越好）

```text
Accuracy = 預測正確的影像數 / 全部影像數
```

- v5：`0.7693 ± 0.0128`。
- 解讀：validation 影像約 76.93% 分類正確。
- 限制：會受到 `nv` 大量樣本主導，不能單獨用來判斷少數疾病的辨識能力。

### 3. Validation macro-F1（輔助指標，越高越好）

```text
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 × Precision × Recall / (Precision + Recall)
macro-F1 = 七類 F1 的平均
```

- v5：`0.5795 ± 0.0158`。
- 用途：同時考慮漏判與誤判，並讓七類權重相同。
- 與 Balanced Accuracy 的差異：Balanced Accuracy 只平均 Recall；macro-F1 同時受到 Precision 與 Recall 影響。

### 4. Recall per class（逐類召回率，越高越好）

Recall 表示某一真實疾病的影像中，有多少被模型正確辨識。v5 三個 seeds 的 validation 平均如下：

| 類別 | 平均 Recall | 樣本標準差 |
|---|---:|---:|
| 日光性角化症／表皮內癌 `akiec` | 0.4966 | 0.1296 |
| 基底細胞癌 `bcc` | 0.6364 | 0.1169 |
| 良性角化症樣病灶 `bkl` | 0.4384 | 0.0365 |
| 皮膚纖維瘤 `df` | 0.2407 | 0.0642 |
| 黑色素細胞痣 `nv` | 0.8989 | 0.0180 |
| 血管性病灶 `vasc` | 0.7879 | 0.0525 |
| 黑色素瘤 `mel` | 0.5110 | 0.0249 |

目前最弱的是 `df`，平均 Recall 約 24.07%；黑色素瘤 `mel` 約 51.10%。這表示即使整體 Accuracy 達 76.93%，少數類別仍有明顯改善空間。

### 5. Confusion Matrix（混淆矩陣）

- 列：真實類別。
- 欄：模型預測類別。
- 對角線：預測正確數量。
- 非對角線：疾病之間的誤判方向。

它可回答「黑色素瘤最常被誤判成哪一類」等問題，是分析模型錯誤型態的工具；但原始數量會受到各類樣本量影響，解讀時應同時查看逐列比例或 Recall。

### 6. Validation ECE（校準誤差，越低越好）

ECE 是 Expected Calibration Error。本專案將預測信心分成 15 個區間，比較每個區間的平均信心與實際正確率，再依樣本比例加權平均。

- 理想值：0。
- v5：`0.0317 ± 0.0059`。
- 粗略解讀：依目前 15-bin 計算方式，模型信心與實際正確率的平均差距約 3.17 個百分點。
- 限制：ECE 會受分箱數量與樣本分布影響；低 ECE 不代表高分類能力，也不代表每個疾病類別都校準良好。

### 7. Validation Loss（訓練監控指標，越低越好）

v5 使用多類別 Cross Entropy。預測越接近正確類別且越有信心，loss 通常越低；對錯誤但過度自信的預測懲罰較大。

- v5 validation loss：`0.6507 ± 0.0152`。
- 用途：觀察最佳化與過擬合。
- 限制：數值沒有直觀百分比意義，只適合在相同資料、損失定義與前處理下比較。

### 8. 三 seeds 平均與樣本標準差

報告中的 `平均 ± 樣本標準差` 來自 seeds 17、42、2026。平均代表典型結果，標準差代表結果對隨機初始化與批次順序的敏感程度。

三個 seeds 只能提供初步穩定性證據，不等同統計顯著性檢定，也不能取代外部資料驗證。

## 四、目前可以與不可以下的結論

### 可以下的結論

- v5 ResNet-18 隨機初始化模型明顯優於 majority baseline。
- v5 三 seed Balanced Accuracy 為 `0.5728 ± 0.0098`，seed 間變異不大。
- v5 優於目前已完成的第一階段 v1 MLP 基準。
- 類別表現不均，`df` 與 `mel` 仍是需要特別改善與監控的類別。

### 目前不可以下的結論

- 不能宣稱已達臨床可用或可取代醫師。
- 不能宣稱對所有人種、膚色、醫院或拍攝設備都有效。
- 不能用 validation 結果代替最終封存 test 結果。
- 不能宣稱預訓練帶來提升，因為 v5 沒有預訓練；必須完成相同設定的 v6 才能比較。
- 第一階段 v2–v4 未完成，不能做計畫書原定的 v4→v5 單一變因歸因。

## 五、最終測試原則

目前 test split 維持封存。應先利用 validation 完成 v5–v14 的架構與超參數決策，選定唯一最終模型後，才對 test split 評估一次。最終報告至少應包含 Balanced Accuracy、macro-F1、Accuracy、ECE、逐類 Recall、混淆矩陣，以及外部資料與膚色公平性限制。

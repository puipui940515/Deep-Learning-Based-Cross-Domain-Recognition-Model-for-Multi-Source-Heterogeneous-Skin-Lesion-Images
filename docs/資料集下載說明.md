本文件記錄目前專案使用的 **ISIC Archive 授權篩選子集**與 **BCN20000** 官方來源、下載方式及使用限制。所有指令均預期從專案根目錄執行：

```text
C:\Users\User\Desktop\test\SkinDetect
```

## 1. ISIC Archive 授權篩選子集

### 子集定義

這不是 ISIC 官方命名的 collection，而是本專案從 ISIC Archive 依下列條件建立的低授權風險子集：

- 診斷必須經 `histopathology` 病理切片確認。
- 只接受逐張 metadata 標示為 `CC-0` 或 `CC-BY` 的影像。
- 排除 `CC-BY-NC` 與其他授權不明的影像。
- 疾病包含 Basal cell carcinoma、Squamous cell carcinoma 與 Melanoma。
- 必須保留每張影像的 `isic_id`、`attribution` 與 `copyright_license`。

本專案在 2026-08-13 建立的查詢快照共 7,886 張：

| 疾病 | 張數 |
|---|---:|
| Basal cell carcinoma（BCC） | 3,037 |
| Squamous cell carcinoma（SCC） | 1,279 |
| Melanoma | 3,570 |
| 合計 | 7,886 |

官方來源：

- ISIC Archive：<https://www.isic-archive.com/>
- ISIC CLI：<https://github.com/ImageMarkup/isic-cli>

### 建立隔離環境

若專案根目錄尚未建立 `.venv-isic`：

```powershell
python -m venv ".venv-isic"
& ".\.venv-isic\Scripts\python.exe" -m pip install isic-cli==12.5.2
```

### 下載指令

```powershell
$isicExe = ".\.venv-isic\Scripts\isic.exe"

& $isicExe image download --search 'diagnosis_3:Basal* AND diagnosis_confirm_type:histopathology AND (copyright_license:CC-0 OR copyright_license:CC-BY)' ".\Dataset\ISIC_Archive\basal_cell_carcinoma"

& $isicExe image download --search 'diagnosis_3:Squamous* AND diagnosis_confirm_type:histopathology AND (copyright_license:CC-0 OR copyright_license:CC-BY)' ".\Dataset\ISIC_Archive\squamous_cell_carcinoma"

& $isicExe image download --search 'diagnosis_3:Melanoma* AND diagnosis_confirm_type:histopathology AND (copyright_license:CC-0 OR copyright_license:CC-BY)' ".\Dataset\ISIC_Archive\melanoma"
```

`isic image download` 會同時下載影像與 metadata。ISIC Archive 是持續更新的資料庫，因此日後重新執行即時查詢時，張數可能與 2026-08-13 的 7,886 張快照不同。不能只用 `--limit` 模擬舊快照，因為這無法保證取得相同的 `isic_id`。

「安全子集」只表示本專案已依 metadata 排除 NC 與授權不明影像，不代表沒有任何法律風險。CC BY 影像仍必須署名，投稿或公開模型前應再次核對逐張 metadata 與期刊政策。

## 2. BCN20000

### 官方來源

- 正式名稱：BCN20000: Dermoscopic Lesions in the Wild
- 建立單位：Hospital Clínic de Barcelona
- Figshare Dataset DOI：<https://doi.org/10.6084/m9.figshare.24140028.v1>
- 資料論文 DOI：<https://doi.org/10.1038/s41597-024-03387-w>
- 授權：CC BY 4.0

本專案使用 **Figshare 獨立發布版本**，不使用 ISIC collection 249 取代它。兩者的授權標示不同，不可混充。

### 下載指令

專案內建下載器會從 Figshare API 取得四個官方檔案的下載網址，並核對 DOI、檔案大小及 MD5：

```powershell
python ".\Dataset\BCN20000\download_bcn20000.py" --workers 8
```

下載完成後解壓、建立可用 metadata 並執行完整性檢查：

```powershell
python ".\Dataset\BCN20000\prepare_bcn20000.py"
```

### 資料量與使用方式

| 分割 | 官方 CSV | 實際可用影像 | 標籤狀態 |
|---|---:|---:|---|
| Train | 12,413 | 12,413 | 有診斷標籤 |
| Test | 6,533 | 6,501 | diagnosis 空白 |
| 合計 | 18,946 | 18,914 | — |

官方 test ZIP 比 test CSV 少 32 張，但 ZIP 與 CSV 均符合 Figshare API 公布的 MD5，因此不是下載中斷。本專案不從其他來源補入這 32 張，以免混入來源或授權不明的影像。

目前多來源皮膚病訓練使用的是 BCN20000 train 中可映射至 HAM10000 七類的資料，並排除 SCC。官方 test 沒有診斷標籤，只能做推論輸出或穩定性檢查，不能計算分類準確率。

整理後主要路徑：

```text
Dataset/BCN20000/images/train/
Dataset/BCN20000/images/test/
Dataset/BCN20000/metadata/available_train.csv
Dataset/BCN20000/metadata/available_test.csv
Dataset/BCN20000/reports/validation.json
```

## 3. 論文與公開使用注意事項

- 論文中應分別引用 ISIC Archive、BCN20000 Dataset DOI 與 BCN20000 資料論文。
- 保留原始 metadata、下載日期、查詢條件、授權與 attribution。
- 不要把「可公開下載」解釋成「可任意重新發布」。
- 公開 GitHub 時，建議只發布程式、manifest、切分表與來源文件，不重新上傳醫療影像或大型 ZIP。
- 正式投稿或公開衍生模型前，應由指導教授、研究機構或期刊再次確認實際使用方式。

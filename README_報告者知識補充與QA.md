## 一、先記住這五件事

1. 目前 UI 預設使用的是 **ConvNeXt-Tiny、ImageNet 初始化、224×224、七分類、多來源混合訓練模型**，不是最新八分類資料版本所訓練的模型。
2. 專案主要看 **Balanced Accuracy**，因為資料類別不平衡；一般 Accuracy 仍會保留，但不能單獨代表模型對每個疾病都表現良好。
3. HAM10000 單一資料集上的最高結果與多來源模型的結果不是同一個評估條件，不能直接用數字大小宣稱哪個模型全面較好。
4. 部位預訓練曾以「初始化權重」及「凍結特徵分支」兩種方式加入；目前證據沒有顯示它優於 ImageNet，章節五應稱為 **雙分支特徵融合**，不是知識蒸餾。
5. 最新治理資料已整理為 86,534 張、八分類並通過資料閘門，但 **尚未完成相應模型訓練**，所以目前 UI 仍只輸出七類，也不能辨識 SCC。

## 二、專案定位

本專案研究的是皮膚影像分類模型，重點包含：

- 比較不同預訓練方式是否能改善疾病分類。
- 評估模型從單一資料集擴展到多來源資料後的泛化能力。
- 處理資料來源差異、重複洩漏、過擬合、設備與構圖差異。
- 透過 UI 顯示多類別機率分布與 Grad-CAM 熱力圖，協助檢查模型行為。

目前成果是 **研究與實驗原型**，不是臨床診斷系統，也不能取代醫師、病理檢查或其他臨床資訊。

## 六、輸入一張圖片後，模型實際做了什麼

1. UI 接收影像並轉成 RGB。
2. 依模型設定縮放／裁切成 224×224 或 384×384。
3. 使用訓練時相同的平均值與標準差正規化；目前主要模型使用每個通道平均值與標準差皆為 0.5。
4. ConvNeXt 或 ResNet 將影像轉換成多層特徵，例如邊緣、紋理、顏色分布與較高階形狀。
5. 分類頭輸出七個 logits。
6. Softmax 將 logits 轉成總和為 1 的類別分布。
7. UI 顯示最高類別、各類機率，以及可用時的 Grad-CAM 熱力圖。

這個流程沒有自動證明影像存在病灶，也沒有先判斷影像是否屬於模型訓練分布。因此一般手部照片也可能被強制分到 NV 等類別。

## 八、部位預訓練、ImageNet 與主體模型的關係

### ImageNet 初始化

ImageNet 預訓練提供一般影像的邊緣、紋理、形狀與物體特徵，再讓整個網路針對皮膚疾病微調。它不是皮膚病模型，但通常能提供較穩定的起點。

### 部位預訓練

部位模型先學習人體部位或人體構圖，再把權重或特徵用於疾病分類。專案曾測試：

- 用部位模型權重初始化，再完整微調疾病分類模型。
- 凍結部位模型作為額外特徵分支，與疾病分類主幹的特徵融合。

在完整微調的 seed 17 對照中：

- ImageNet 初始化 Balanced Accuracy：78.13%。
- 部位權重初始化 Balanced Accuracy：68.61%。
- 差距約 9.52 個百分點。

但部位初始化只有一個 seed，因此只能當作方向性證據，不能宣稱已普遍證明 ImageNet 一定較好。

可能原因包括 ImageNet 的影像多樣性較大、學到較通用的局部紋理與形狀，以及部位任務與皮膚病灶辨識的目標並不完全一致。這些是合理解釋，不是目前實驗直接證明的因果結論。

## 九、章節五的「雙分支特徵融合」到底是什麼

同一張影像同時進入兩個分支：

- **凍結部位特徵分支**：參數不更新，輸出固定維度的部位／構圖特徵。
- **疾病分類主幹**：繼續學習皮膚病相關影像特徵。

兩邊的特徵在分類頭前串接，再輸出七類機率。反向傳播時只更新疾病分類主幹與融合分類頭，凍結分支不更新；推論時兩個分支都必須存在。

這不應稱為教師—學生或知識蒸餾，因為：

- 沒有用教師模型的機率分布作為軟標籤。
- 沒有蒸餾損失去逼近教師輸出。
- 沒有訓練完成後只保留學生模型。

它與一般預訓練的差別是：一般預訓練把權重作為主幹的起點，之後通常只保留一個模型；雙分支融合則保留一條凍結特徵路徑，在每次推論時都提供額外輸入。

三個 seed 的結果中，凍結 ImageNet 特徵分支平均 BA 為 76.04%，凍結部位特徵分支為 76.13%，差距約 0.10 個百分點，實質上沒有顯示部位分支的獨特優勢。

這個結果只能否定「目前這種部位特徵融合方法已帶來明確提升」，不能推論所有部位資訊都無效。把解剖部位當作輔助標籤的多任務學習仍未在這批實驗中完成驗證。

## 十、常見指標怎麼解釋

### Accuracy

\[
\mathrm{Accuracy}=\frac{\text{預測正確的樣本數}}{\text{全部樣本數}}
\]

直觀，但容易被大類別主導。例如模型只要很會預測數量最多的 NV，Accuracy 就可能看起來不錯。

### Recall（召回率）

對類別 \(c\)：

\[
\mathrm{Recall}_c=\frac{TP_c}{TP_c+FN_c}
\]

表示真正屬於該類的樣本中，有多少被成功找出。漏判越多，召回率越低。

### Balanced Accuracy

\[
\mathrm{Balanced\ Accuracy}=\frac{1}{K}\sum_{c=1}^{K}\mathrm{Recall}_c
\]

先計算每一類的召回率，再等權平均。大類與小類各占同樣份量，適合本專案的不平衡資料。

### Precision 與 F1

\[
\mathrm{Precision}_c=\frac{TP_c}{TP_c+FP_c}
\]

\[
F1_c=\frac{2\cdot \mathrm{Precision}_c\cdot \mathrm{Recall}_c}{\mathrm{Precision}_c+\mathrm{Recall}_c}
\]

Precision 關心「模型說是這一類時有多常正確」，Recall 關心「真正的這一類找回多少」。F1 是兩者的調和平均，任何一邊很差都會拉低分數。

### Macro-F1

\[
\mathrm{Macro\text{-}F1}=\frac{1}{K}\sum_{c=1}^{K}F1_c
\]

先為每個類別各算一個 F1，再等權平均，用來觀察小類別是否也有合理的精確率與召回率。

### Cross-Entropy Loss

\[
\mathcal{L}_{CE}=-\frac{1}{N}\sum_{i=1}^{N}\log p_{i,y_i}
\]

模型若把正確類別的機率給得越低，扣分越重；若自信地預測錯誤，損失會特別大。訓練的反向傳播就是依這個損失調整權重，並不是使用遊戲式的獎勵函數。

### ECE

\[
\mathrm{ECE}=\sum_b\frac{|B_b|}{N}\left|\mathrm{acc}(B_b)-\mathrm{conf}(B_b)\right|
\]

ECE 衡量信心與實際正確率是否一致，越接近 0 越好。ECE 高表示模型可能過度自信或過度保守。

### Top-2 Accuracy

只要真實標籤位於模型最高的兩個候選中就算正確。它適合表達皮膚表面影像可能對應多個相似疾病，但不能取代正式診斷。

### 最低召回率

\[
\min_c \mathrm{Recall}_c
\]

用來確認最弱類別是否被模型忽略。即使平均分數不差，最低召回率過低仍表示某個疾病幾乎無法被可靠找出。

### 樣本標準差

使用不同 seed 重複訓練後，標準差描述結果的波動。標準差越小代表模型對隨機初始化與資料抽樣較穩定，但不代表模型一定較準確。

## 十一、目前主要問題為什麼依序是這四項

### 1. 來源差異

不同資料集可能使用不同相機、皮膚鏡、解析度、背景、照明、裁切方式及收案族群。模型可能先學會辨識來源，再利用來源與標籤的關聯作答。

### 2. 資料重複洩漏

同一病灶可能有多張照片，或同一影像可能同時存在不同資料集中。如果只隨機切圖片，同一病灶可能同時進入訓練與驗證，造成分數虛高。因此目前採用病灶或病人層級分組，並檢查雜湊與近重複影像。

### 3. 過擬合

訓練 BA 95.79%，跨來源驗證平均 BA 69.37%，表示模型對訓練資料的掌握遠好於未見資料。來源特徵與資料重複都可能進一步放大這個問題。

### 4. 設備與構圖差異

長寬比留白、背景材質、色溫、飽和度、拍攝距離與病灶占畫面比例，都可能成為捷徑。這些因素需在資料治理、增強、來源分層評估與未來的外部驗證中處理。

## 十二、Grad-CAM 熱力圖該怎麼看

Grad-CAM 顯示的是「哪些區域對目前類別分數影響較大」，不是：

- 精確的病灶分割。
- 病理證據。
- 模型診斷正確的證明。
- 因果關係的證明。

如果熱點集中在背景、床單、邊框或皮膚以外區域，可能表示模型使用了來源、設備或構圖捷徑，也可能是輸入超出訓練分布。Grad-CAM 本身解析度較粗，本專案又沒有病灶遮罩作為定位真值，因此只能當作模型稽核工具。

## 十三、NoiseFilter 是什麼，為什麼沒有成為主線

NoiseFilter v1 包含：

- LogContrast：調整局部對比。
- IlluminationFlatten：削弱不均勻照明。
- GCC：調整色彩／灰階一致性。
- PeripheralReference：利用周邊區域作為亮度或色彩參考。

目標是降低光照與資料來源差異，但實驗結果為：

- 第一階段 MLP 的平均 Balanced Accuracy 下降約 3.09 個百分點。
- 第二階段從零訓練的 ResNet 平均 Balanced Accuracy 下降約 6.73 個百分點。
- seed 間標準差放大約 4.49 倍。

因此 v1 沒有證明能改善分類，已退出主線。v2 修正了對比保留問題，但目前只完成前處理層級檢查，尚未完成新的分類對照實驗。

## 十四、為什麼一般手部照片會被高信心判成黑色素細胞痣

主要原因是目前分類器屬於封閉集合：

1. 模型沒有「無病灶」「未知」「非皮膚病影像」類別。
2. Softmax 會把全部機率分配給既有七類，即使輸入不屬於任何一類。
3. 訓練資料以病灶影像為主，缺少正常皮膚、模糊照、背景照及其他疾病的負樣本。
4. 模型可能依賴膚色、背景、紋理或構圖等捷徑。
5. 未完成針對分布外輸入的拒答與信心校正。

因此 90% 只是「在這七個選項中，NV 的相對分數最高」，不是臨床上的患病機率。

未來可加入：影像品質閘門、是否存在病灶的前置模型、正常／未知類別、分布外偵測、溫度校正，以及信心不足時的拒答機制。這些功能目前仍是後續工作，不應在報告中說成已完成。

## 十五、UI 現況

目前 UI 可以：

- 從固定模型登記檔載入模型。
- 上傳單張影像並輸出七類機率分布。
- 顯示 Grad-CAM 熱力圖。
- 切換已登記的階段性模型。

目前 UI 不包含：

- 臨床驗證與醫療器材認證。
- 使用者帳號、資料庫與完整隱私流程。
- 多張批次分析。
- 可靠的未知類別拒答。
- 最新八分類資料所訓練的 SCC 模型。

## 十六、常見 QA 與建議答法

### Q1：為什麼不用 Accuracy 就好？

因為資料非常不平衡，HAM10000 約 67% 是 NV。Accuracy 可能被最大類別主導；Balanced Accuracy 讓每個疾病的召回率等權計算，更適合檢查小類別是否被忽略。我們仍同時報告 Accuracy、Macro-F1、ECE 與逐類召回率。

### Q2：為什麼單一 HAM10000 可以到 80.97%，混合資料卻只有約 69%？

兩者不是同一個測試條件。HAM 單來源模型只面對一種資料分布；混合模型需要同時面對 HAM、BCN 與 PAD 的設備、構圖及收案差異。跨來源分數較低反映任務更難，不能直接解讀為模型退步。

### Q3：ImageNet 又不是皮膚資料，為什麼比部位預訓練好？

目前合理解釋是 ImageNet 的規模與影像多樣性讓模型先學到更通用的視覺特徵，而部位任務和病灶分類之間可能存在任務落差。但目前部位初始化只有一個 seed，這是方向性結果，不能宣稱已證明普遍因果。

### Q4：部位模型既然沒有改善，是否代表部位資訊沒有用？

不是。只能說目前測試的權重初始化與凍結特徵融合沒有顯示明確優勢。把解剖部位當成結構化標籤或多任務輔助目標仍值得測試，而且這與把兩個視覺模型直接串接是不同方法。

### Q5：章節五是不是教師—學生模型？

不是。沒有軟標籤、蒸餾損失或教師輸出模仿；它是凍結特徵分支加上可訓練疾病主幹的雙分支融合。兩個分支在推論時都要運行。

### Q6：為什麼熱力圖會看背景？

這可能表示模型學到來源或構圖捷徑，也可能因為影像超出訓練分布。Grad-CAM 只顯示影響分類分數的區域，不能當作病灶分割或正確性證明。

### Q7：模型為什麼對沒有病灶的手給出 90% 信心？

因為模型只有七個已知選項，Softmax 必須在其中分配機率；它沒有未知或正常類別，也沒有完善的分布外拒答。這顯示高信心不等於真實診斷機率。

### Q8：為什麼不用所有 86,534 張重新訓練？

資料治理 v2 已完成，但標籤從七類擴充到八類，程式、分類頭、權重載入、指標與 UI 都需要同步調整。為了避免把「資料準備完成」誤當成「模型已完成」，目前先保持兩者狀態分離。

### Q9：現在有沒有完全獨立的外部測試？

目前沒有一個同時符合未參與訓練、標籤完整、來源獨立且從未用於選模的乾淨外部基準。PAD 已進入混合訓練，BCN 官方 test 沒有標籤；HAM sealed test 保持未開啟。未來可使用 leave-one-source-out 設計。

### Q10：治理後分數提高了嗎？

治理後三種子平均約 70.78%，但資料分割與樣本條件已改變，舊混合模型又只有一個 seed，所以不能直接稱為顯著提升。治理的第一目的，是讓評估更可信，而不是保證數字一定變高。

### Q11：模型可以拿來看診嗎？

不可以。目前是研究原型，資料分布、未知輸入、信心校正、族群公平性、臨床流程與法規驗證都尚未完成。

### Q12：膚色與人種有納入嗎？

不能從影像自行推斷人種。未來若資料有可靠且合規的 Fitzpatrick 或 Monk Skin Tone 標註，可以做分層公平性評估；膚色量表也不等同於人種。

## 十七、報告時不要超出證據的說法

避免下列說法：

- 「模型準確率有 90%，所以可用於診斷。」
- 「熱力圖證明模型找到病灶。」
- 「部位資訊完全沒有用。」
- 「資料治理已顯著改善模型。」
- 「目前模型已使用全部 86,534 張影像。」
- 「目前 UI 已支援 SCC 八分類。」
- 「Softmax 90% 就是 90% 患病機率。」
- 「不同資料集的數字可以不考慮分割與來源直接比較。」
- 「2s 門檻就是正式的統計顯著性。」

比較穩妥的表達：

- 「在目前資料與評估設定下觀察到……」
- 「結果顯示方向性差異，但仍需更多 seed 或外部資料驗證。」
- 「這是分類信心，不是臨床患病機率。」
- 「目前沒有觀察到超過專案穩健性門檻的差異。」
- 「資料已完成治理，但相應的新模型尚未訓練。」

## 結論

本結果只適用於未預訓練 ResNet-18、固定 alpha `[0.25, 0.5, 0.5, 0.5]` 與 HAM 七類設定。BCN20000、PAD-UFES-20 與 ISIC Archive 的特定相容類別在本次固定 ensemble 評估中出現正向差值；但「全部相容標籤」乾淨差值 +0.0186 小於搭載組 seed std 0.0234，依計畫書 §3.4 不得納入架構，也不能概括為已提升泛化能力。

HAM10000 validation 的乾淨 ensemble BA 由 0.5861 降至 0.5394，差值 -0.0466（95% CI -0.0918 至 -0.0042）。外部來源的絕對 ensemble BA 約 0.25–0.32，仍偏低。若部署環境接近 HAM10000，基線較適合；外部來源的正向結果只能作為後續 ablation 與獨立 OOD 驗證的研究線索。

同族光照 sanity check 的一致率提高不能單獨視為模組效益。ISIC ID 稽核結果為：HAM10000 對 ISIC 安全子集 0 筆、BCN collection 249 對 ISIC 安全子集 0 筆、HAM validation 對 ISIC mapped 0 筆；此結果只排除 ID 重疊，不能排除不同 ID 的相同內容。

# 全資料集正式測試總結論

## 測試範圍

- 全部本地影像條目：39,933 張。
- 可進行相容疾病分類評估：22,199 張。
- 其餘 17,734 張只用於乾淨／擾動預測穩定性，不推測缺失或不相容標籤。
- HAM10000 train 與封存 test 不計算正式分類指標；`ham_test_labels_used = false`。
- 每階段包含 baseline／搭載版、三個 seeds，並對 ensemble 差值執行依類別分層 bootstrap 1,000 次。

| 階段 | 全部相容標籤乾淨 BA 差值 | 全部相容標籤擾動 BA 差值 | 全影像一致率 | 全影像 L1 漂移 | 判斷 |

## 正式結論

第一階段 MLP 未出現可納入架構的跨來源分類效益。第二階段結果只適用於未預訓練 ResNet-18、固定 alpha `[0.25, 0.5, 0.5, 0.5]` 與 HAM 七類設定。雖然部分外部來源的固定 ensemble 差值為正，但全部相容標籤乾淨差值 +0.0186 小於搭載組 seed std 0.0234，依計畫書 §3.4 判定為未通過，不概括為提升泛化能力。

第二階段 HAM10000 validation 的乾淨 ensemble BA 由 0.5861 降至 0.5394，差值 -0.0466（95% CI -0.0918 至 -0.0042）。BCN20000、PAD-UFES-20 與 ISIC Archive 的正向結果應視為後續 ablation 與獨立 OOD 測試線索。外部來源絕對 BA 約 0.22–0.32，且目前 `IlluminationPerturb` 與濾鏡目標屬同一擾動族；穩定性結果只能作 sanity check，不能當成獨立的模型改進證據。

本結果適合作為期末專題的探索性跨資料來源實驗證據；若用於論文，不應將其直接解釋為臨床有效性。A1–A3 的 ISIC ID 交集均為 0，因此 PAD-UFES-20 並非唯一通過 ID 重疊檢查的集合；但 PAD 是唯一不依賴 ISIC ID 稽核、來源結構上獨立的集合。不同資料來源的疾病定義、類別組成與攝影條件不同，且尚未做不同 ID 內容去重；後續應加入病人層級獨立外部測試、真實裝置／膚色分層與校準分析。

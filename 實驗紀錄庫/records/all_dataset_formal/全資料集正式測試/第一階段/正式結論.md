## 結論

第一階段（MLP、64×64、固定 alpha `[0.25, 0.5, 0.5, 0.5]`、HAM 七類設定）沒有帶來一致的跨來源分類增益。全部相容標籤的乾淨 ensemble BA 下降；擾動條件的整體差值很小且信賴區間跨 0。ISIC 擾動資料呈現小幅正向結果，但不足以抵消其他來源及整體乾淨效能的下降。

同族光照 sanity check 的一致率雖提高，但不可單獨描述為模組效益。外部來源的絕對 BA 約落在 0.21–0.28，仍屬偏低範圍。若以分類效能為主要目標，不建議以本設定取代第一階段基線。

ISIC ID 稽核結果為：HAM10000 對 ISIC 安全子集 0 筆、BCN collection 249 對 ISIC 安全子集 0 筆、HAM validation 對 ISIC mapped 0 筆。因此保留聚合列；此結論只代表 ID 層級未重疊，不能排除不同 ID 的相同內容。

# 等比例縮放與補邊（letterbox）

> **2026-10-09更新**：NoiseFilter v2已改為在真實矩形影像上處理，之後才補邊；以下停用／阻擋描述屬舊狀態。新版排程與實作請看 `README_必跑NoiseFilter_v2排程.md`。

這解決長寬比變形和新版 R0 隨機裁切丟失視野的問題，不是JPEG壓縮，也不會消除縮小影像造成的細節損失。

例如600×400圖片，直接拉伸為224×224會變形；新版先等比例縮到224×149，再上下補邊成224×224。允許四捨五入造成最多約一像素的尺寸誤差。

## 新版 CP005 設定

`模型改進/config.json`：

```json
"preprocessing": {
  "mode": "letterbox",
  "fill": [124, 116, 104],
  "allow_upscale": true
}
```

- 所有來源同一規則，RGB固定補邊值接近ImageNet平均值，不按來源選不同顏色。
- EXIF方向修正→RGB→指定實驗裁切（R0／LOSO為不裁切）→等比例縮放真實影像→訓練時翻轉／顏色增強→置中補邊→Tensor→ImageNet正規化。先縮放再增強，避免在原始大圖上增加不必要的運算。
- 補邊在顏色增強之後，避免人工邊框也被隨機變色。
- letterbox模式取消原RandomResizedCrop，不再切掉原圖視野；R1/D2若被明確選用仍會先執行其指定裁切，並仍受既有閘門限制。
- 驗證與CP005的TTA入口都使用相同的Images前處理。新checkpoint保存這份設定；不能拿舊模型套新版前處理後混稱同一實驗。
- 設成`legacy`可回復原訓練RandomResizedCrop、驗證強制正方形縮放。歷史checkpoint沒有此欄位時仍走legacy，不偷偷改行為。
- 本次未改UI現役模型的輸入方式，也未啟動正式訓練。新模型日後接入UI必須從其checkpoint讀取此設定。

## NoiseFilter V2的限制

補邊不是皮膚，不能當成色調、光照或白平衡參考。現有V2尚未能完整排除這些區域，因此letterbox模式禁止搭載V2，準備入口記錄`blocked_preprocessing`，不做偽校準／探針。這是功能相容性阻擋，不是新的效能失敗。

先前未補邊的800張校準／2400張探針結果完整保留，但不能用於新模式；指紋已改變。未來須讓濾波統計完整支援有效像素遮罩，或在補邊前對真實影像濾波，再重新校準與測試，才能解除阻擋。

## 仍存在的風險

- 224輸入仍會減少大圖細節，超長條圖片的有效內容尤其小；若細節不足需另外比較更高解析度或多區塊，而非無限制增加padding。
- 補邊比例反映原始長寬比，可能成為來源辨識線索；不能宣稱padding解決來源偏差。
- 本次同時取消隨機裁切，因此與舊結果的差異不能全歸因於padding單一因素。
- 原Dataset圖片不改寫，舊結果不覆寫。持續排程若已有舊status，會因指紋不符而拒絕混跑，需另建版本，不要刪掉指紋保護。

## 啟動

原指令不變，新版排程使用letterbox：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\模型改進\run_continuous.ps1"
```

新版會略過不相容濾波分支，執行基準／留一來源實驗。`reports/等比例補邊比較.png`提供四來源原圖、直接縮放與補邊示例，不是模型效能結果。

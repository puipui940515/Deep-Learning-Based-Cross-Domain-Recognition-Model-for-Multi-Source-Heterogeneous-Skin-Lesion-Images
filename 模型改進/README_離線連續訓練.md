# CP005 多日連續訓練（2026-10-08）

> 後續更新：使用者改為要求持續執行，請改看 `README_持續安全訓練.md` 與 `run_continuous.ps1`。下述為舊有限排程；新增安全檢查已改變程式指紋，因此舊 seed17 不再與新版直接合併或跳過，新版有限排程也會重新建立結果，原結果保留。

## 啟動

在專案根目錄執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\模型改進\run_unattended.ps1"
```

只檢查、不訓練：在指令最後加上 `-CheckOnly`。

## 順序與目的

1. R0 seed 17：已有完成結果，設定與程式指紋相同才跳過。
2. R0 seed 42、2026：補齊三種隨機種子，測量基準穩定性。
3. L-PAD seed 17：訓練與選模排除 PAD，評估未見來源的泛化。
4. L-BCN seed 17：訓練與選模排除 BCN。
5. L-HAM seed 17：訓練與選模排除 HAM。
6. 產生 R0 三種子統計與中文曲線、溫度校準與集成報告；三個排除來源實驗只屬單種子探索，不宣稱正式顯著性。

每個任務獨立從 ImageNet 初始化 ConvNeXt-Tiny 八分類，不接續上一個模型權重。每次最多 12 epochs、耐心值 4，224 像素、實際 batch 16／有效 batch 32。維持原有混合精度、Mixup、標籤平滑、抽樣與資料切分；不為填滿時間任意增加 epochs。抽樣為有放回加權抽樣，不保證每輪遍歷每張圖片。

R0 使用四來源；排除來源實驗刻意改變訓練來源。所有任務分開保留 val_select（選模）與 val_assess（評估），封存測試集不使用。排除來源只在評估時出現，其專屬溫度也不會用來擬合校準。D2 裁切視覺檢查未通過，相關受限分支不排入。

## 無人值守行為

- 一次只跑一個任務，自動接續，不需手動輸入下一條命令。
- 完成結果不覆寫；相同設定的中斷任務從 `last.pt` 接續（epoch 邊界，當輪未儲存進度會重跑）。無檢查點的失敗目錄保留，建立新目錄。
- 再次執行同一指令即可跳過完成項目。多份相容結果時停止，避免偷偷選錯。
- 任務錯誤即停止，詳細資訊在 `模型改進/results/unattended_cp005/status.json` 與各任務 `.log`；不無限重試。
- 終端顯示任務與日誌位置；每批進度寫進日誌。可用 `Get-Content -Tail 20 -Wait` 讀取對應日誌。
- 偵測到其他 `train.py` 程序時拒絕開始，避免 GPU 競爭。不要同時開其他訓練。
- 執行期間請求 Windows 不因閒置睡眠；螢幕可關。請插電、保持散熱，別關閉終端、關機或合蓋；不能阻止 Windows 更新重啟。
- 訓練器、設定與 manifest 不要在排程中修改。排程器放在獨立 queue 目錄，不改變已有訓練程式指紋。

五個新任務耗時可能一至數天，取決於早停、I/O 與 GPU；不保證提高準確率。完成後自動結束，不持續監控、不自動關機。

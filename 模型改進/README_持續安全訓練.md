## 開始／停止

在專案根目錄啟動（不會因完成預定任務就結束）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\模型改進\run_continuous.ps1"
```

回來後，在另一個終端要求安全停止：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\模型改進\stop_continuous.ps1"
```

會等目前 epoch 訓練、選模及存檔完成再退出，不是即刻停止。Ctrl+C 為立即中止，當輪進度可能丟失；先前驗證通過的檢查點保留。恢復前手動刪除 `模型改進/results/continuous/STOP`，再執行啟動指令。請先確認錯誤原因，勿盲目重試失敗任務。

## 固定協定

- 2026-10-08 更新：先執行四來源 CP005 專用 NoiseFilter V2 校準／探針，再以種子 17、42、2026 逐一配對「無濾波／通過閘門的完整濾波／通過閘門的移除色調版」。完整規格見 `README_NoiseFilterV2_收益優先排程.md`。
- 配對實驗之後，三個種子分別跑 L-PAD、L-BCN、L-HAM（全部不使用濾波）。完成後才由種子 10000 開始，循環上述通過篩選的對照與排除來源任務。不依疾病訓練分數改超參數或只加碼贏家。
- 每個任務獨立從 ImageNet 初始化 ConvNeXt-Tiny 八分類，最多 12 epochs、耐心值 4。不是把同一權重無限訓練。
- 每個 seed、任務獨立資料夾；不覆蓋已完成模型、不更新 UI 默認模型。
- 使用固定 train／val_select；不執行 val_assess 推論、不擬合評估集、不用封存測試集。回來後預先指定比較與種子集合再評估，不從大量種子中只報告最高分。
- 新安全程式具有新指紋，原 seed17 結果完整保留，不混進新版正式統計。
- 每完成任務自動更新選模分割的中文曲線、CSV、平均／標準差及相同種子的濾波差值。這不是獨立評估或原 P1 報告；後續評估需獨立執行。

## 保護範圍與限制

- 每批檢查輸入、logits、loss；更新前检查反縮放後的梯度範數，非有限值即停止（AMP 溢位也採保守停止，不自動調參）。
- 存檔前遞迴檢查模型／optimizer／隨機狀態等；寫暫存檔、flush/fsync、重新讀取與非有限值驗證後才原子替換。
- 恢復時檢查 checkpoint；評估 logits 同樣檢查。異常不覆蓋之前的正常檢查點，不自動重試或悄悄接續污染權重。
- 剩餘空間低於 5 GiB 停止；不自動刪歷史模型。這是安全優先，不承諾無論任何錯誤都繼續跑。
- 單一佇列鎖、檢查已執行的 train.py；資料與程式指紋變動時停止。
- 狀態／日誌：`模型改進/results/continuous/`。可在各任務 log 看逐批進度。
- 保持插電、散熱、不要合蓋。執行期間請求避免閒置睡眠；不能阻止手動睡眠、更新重啟、硬體或檔案系統故障。
- 有限值不是品質保證：權重未出現 NaN 不代表準確率提高或没有過擬合。固定早停與獨立任務降低風險，但仍須後續評估。檢查有運算／I/O 額外成本。

這不是新的資料清理或去重稽核；沿用既有 CP005 切分，不能藉此保證原資料絕無洩漏。無限訓練可能耗盡磁碟，所以保留安全停止條件。

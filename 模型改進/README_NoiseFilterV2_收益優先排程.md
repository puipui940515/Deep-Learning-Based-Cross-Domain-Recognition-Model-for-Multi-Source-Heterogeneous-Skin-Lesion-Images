## 為什麼更值得跑

優先回答「濾波是否幫忙、色調段是否傷害、效果是否穩定」，而不是先增加大量重複種子。完整濾波與移除色調版均獨立比較無濾波，其他訓練設定不變。若篩選未通過，就不花數小時訓練該分支。兩種皆未通過則補齊無濾波三種子與留一來源實驗。

## 執行順序

1. **CP005 專用校準與篩選**：僅 train；按 `cp005_group` 的固定雜湊分出不重疊的校準／探針群組池。校準最多每來源 200 張，探針最多每來源 600 張，来源內按疾病輪流抽樣。實際 record IDs 保存。
2. **機制門檻**：凍結 ImageNet ConvNeXt-Tiny 特徵、群組分層五折線性探針。來源 BA 至少下降 3 個百分點，且每個來源的疾病 BA 都不能下降超過 2 個百分點。相比舊版只檢查兩個來源疾病訊息，本次更嚴格；是資源篩選規則，不是顯著性檢定，也不是保證疾病模型有效。
3. **配對訓練**：seed17 無濾波→通過的完整濾波→通過的移除色調版；再按同樣順序 seed42、2026。均為四來源八分類、相同切分、224 輸入、相同有效 batch、最多12輪、耐心4。
4. **留一來源**：L-PAD／L-BCN／L-HAM 各17／42／2026。全部無濾波，避免將四來源校準資訊帶入應被排除的來源；沒有聲稱完成「濾波的留一來源對照」。
5. **若仍未停止**：由10000開始新增種子，固定輪流執行上述有效分支，不挑最好種子、不自動延長模型 epochs。

三種子主對照最多9次訓練，留一來源9次；由門檻決定是否省略濾波任務。即使只跑完前幾項，也會保留各自結果並更新報表。無限追加的邊際收益較低，不保證模型變好。

## 接入方式與隔離

- 濾波作用於反正規化的 RGB 像素，FP32 計算；輸出再以 ImageNet mean/std 正規化。
- 幾何／顏色增強後、MixUp 前濾波，避免對混合影像估計照明；主模型一次 forward，不重複濾波。
- 濾波器凍結；AdamW 的 layer decay 分组建立在原 backbone 上。推論也使用相同濾波。
- 新四來源校準不沿用治理 v1 校準；校準、探針、程式與模型均有指紋。
- 不同 profile、seed 獨立 run_id，不覆寫歷史結果；新版與舊版程式結果不直接混算。
- 只讀取 val_select 做早停／選模；不推論 val_assess、不使用封存測試集、不改 UI 默認模型。
- 不加入來源對抗、CORAL/MMD 或其他同時變動，避免無法判斷改善來自哪裡。

## 指令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\模型改進\run_continuous.ps1"
```

先檢查不訓練：上述指令加 `-CheckOnly`；只確認訓練入口，不代表 NF2 實際探針通過。

安全停止：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\模型改進\stop_continuous.ps1"
```

準備階段會在校準／探針結束後檢查停止要求；訓練階段在 epoch 存檔後停止。NaN／Inf、磁碟不足或系統錯誤會停止整個排程；探針正常跑完但分數不過門檻則只略過該分支。

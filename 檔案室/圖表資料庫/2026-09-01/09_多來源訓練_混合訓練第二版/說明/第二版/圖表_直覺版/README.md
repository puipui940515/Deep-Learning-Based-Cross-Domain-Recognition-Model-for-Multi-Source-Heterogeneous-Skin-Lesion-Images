# 直覺版圖表說明

- `01_各來源Train與Validation平衡準確率.png`：使用同一個固定第 6 輪 `best.pt`，分別對三個來源的完整 train 與 validation 做非增強純推論。這是判斷過度擬合最直接的圖。
- `02_第一版第二版Validation直覺比較.png`：只比較第一版與第二版在相同 validation 清單上的 Balanced Accuracy。
- `03_只顯示Validation的訓練曲線.png`：移除容易誤解的訓練過程即時指標，只保留各來源 validation 與等權平均。

第一張圖使用固定模型、相同前處理與完整資料，不是訓練途中累積的 batch 指標。

| 來源 | Train BA | Validation BA | 落差 |

# 全資料集快速測試總結論

五個本地資料來源均已納入固定快速抽樣，共 924 張。HAM10000 只使用 validation；SCIN、SCC 與 BCN 無標籤 test 不硬套 HAM 類別，只計算推論穩定性。

- 第一階段：穩定性提高，但乾淨分類能力下降，不採用。
- 第二階段：整體快速集乾淨／擾動 BA 約持平，預測一致性與機率穩定性改善；BCN、PAD 有正向訊號，但 HAM 與 ISIC 仍有退化。
- 正式結論不變：固定核心 noisefilter 不能直接取代 v1 或 v5。
- 新發現：第二階段可能具有跨來源光照韌性價值，值得後續以較低 alpha、逐子濾鏡 ablation，以及 BCN／PAD 全量外部驗證確認。

本測試是快速探索，不是正式全量外部驗證，也沒有使用任何資料調整模型或挑選 checkpoint。

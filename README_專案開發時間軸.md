# SkinDetect 專案開發時間軸

本文件依照時間整理 SkinDetect 專案至今完成的資料、模型、實驗、驗證與介面工作。

> 重要區分：HAM10000、BCN20000、PAD-UFES-20 與 ISIC 資料用於皮膚疾病相關訓練或驗證；DensePose／COCO 用於人體部位辨識預訓練，不是皮膚病資料集。

## 時間軸

### 前期建置：資料集與授權整理

- 調查可公開取得的皮膚疾病資料集。
- 檢查資料來源、授權條款及論文使用限制。
- 清除來源不明或授權疑慮較高的資料。
- 建立 Dataset 資料夾及資料來源說明。
- 下載並整理 HAM10000、BCN20000 與 ISIC 安全子集。
- 依照資料來源重新分類，避免不同來源的資料互相混淆。

### 第一階段：基礎皮膚病分類

- 以 HAM10000 建立第一版皮膚病分類流程。
- 建立固定的訓練集、驗證集與測試集切分。
- 使用多個 Seed 進行訓練與比較。
- 記錄 Accuracy、Balanced Accuracy、macro-F1、ECE、Loss 及各類別召回率。
- 建立第一階段的模型、設定、結果與實驗紀錄資料夾。

### 第二階段：正式疾病檢測模型

- 建立第二階段疾病分類模型。
- 比較純淨初始化、ImageNet 預訓練及其他特徵搭載方式。
- 進行短訓練、正式訓練與多 Seed 對照。
- 保存訓練曲線、最佳權重與驗證結果。

### 2026-08-15：NoiseFilter 設計稽核

- 整理 NoiseFilter 的功能與處理流程。
- 檢查濾波器是否改變模型使用的影像資訊。
- 測試隨機雜訊與隨機遮蔽輸入特徵。
- 保存設計稽核結果與實驗曲線。

### 2026-08-24：部位辨識預訓練

- 使用 DensePose／COCO 人體部位標註資料建立部位辨識任務。
- 訓練人體部位辨識模型並保存為重要資產。
- 測試加入隨機雜訊與隨機遮蔽後的部位預測表現。
- 保存部位預訓練模型、曲線與評估結果。

> 此階段訓練的是人體部位辨識能力，不是皮膚疾病分類。DensePose／COCO 不列入皮膚病資料集。

### 2026-08-24：部位模型接續疾病分類

- 凍結部位辨識模型的權重。
- 將凍結模型接到第二階段疾病分類流程。
- 測試凍結線性探測、完整微調及並行特徵輸入。
- 比較部位預訓練是否改善後續皮膚病分類。

### 2026-08-25：預訓練方式比較

- 比較純淨模型、ImageNet 預訓練模型與部位辨識預訓練模型。
- 確認不同模型使用相同的資料切分與訓練尺度。
- 建立三條曲線的直觀比較圖。
- 記錄各模型的最佳驗證結果。

### 2026-08-25：ConvNeXt-Tiny 對照

- 建立 ConvNeXt-Tiny 疾病分類模型。
- 比較純淨初始化、ImageNet 初始化及部位預訓練的結果。
- 整理模型結構與參數量。
- 建立相同資料與訓練條件下的對照曲線。

### 2026-08-25：跨資料來源推論驗證

- 在 HAM10000、BCN20000、PAD-UFES-20 與 ISIC Archive 等來源執行只推論驗證。
- 驗證過程不進行額外訓練。
- 比較模型在不同資料來源上的 Balanced Accuracy 與其他指標。
- 發現模型在 HAM10000 以外資料來源的泛化能力不足。

### 2026-09-01：多來源混合訓練第一版

- 混合 HAM10000 與 BCN20000 建立訓練集。
- 比較混合前後在兩個資料來源上的表現。
- 保存訓練曲線、來源別驗證結果及各疾病召回率。

### 2026-09-01：多來源混合訓練第二版

- 在混合訓練中加入 PAD-UFES-20。
- 建立 HAM10000、BCN20000 與 PAD-UFES-20 三來源訓練流程。
- 增加混合資料量並執行煙霧測試與正式訓練。
- 產生來源別曲線及較直觀的比較圖表。

### 2026-09-06：資料治理與泛化修復

- 統一不同資料集的疾病標籤定義。
- 按照以下順序處理資料問題：

  1. 來源差異。
  2. 資料重複與洩漏。
  3. 過擬合。
  4. 設備與構圖差異。

- 重新建立較嚴格的訓練、驗證與測試資料流程。
- 執行資料治理後的正式訓練。

### 2026-09-07：較長正式訓練

- 使用更多資料與較長訓練週期。
- 保存最佳模型與完整訓練紀錄。
- 比較短版與長版訓練的來源別表現及穩健選模分數。

### 2026-09-08：基底模型篩選

- 使用十張測試影像比較目前可用模型。
- 檢查疾病機率分布、預測結果及 Grad-CAM 熱力圖。
- 比較模型的分類表現與熱力圖合理性。
- 以測試結果選擇後續實驗的基底模型。

### 2026-09-08：可切換功能的正式訓練

- 建立統一的設定檔。
- 讓資料增強、額外影像特徵、機率校準與熱力圖稽核等功能可以獨立開關。
- 保存每次正式訓練的設定與曲線，方便後續進行消融實驗。

### 2026-09-08：關卡式課程學習

- 建立由簡單資料集逐步前進到較困難資料集的訓練方式。
- 使用 Balanced Accuracy、Top-2、ECE、最低類別召回率與連續通過次數判定是否晉級。
- 第一關使用 HAM10000。
- 第一次執行在最大 Epoch 內未達過關條件，因此流程停在第一關。

### 2026-09-08：UI 整合

- 建立 SkinDetect 實驗與實際使用共用的 UI 原型。
- 支援讀取已保存的疾病分類模型與部位辨識模型。
- 顯示各疾病的中文名稱與預測機率分布。
- 加入 Grad-CAM 熱力圖。
- 加入模型選擇與固定模型資料夾。
- 加入訓練參數欄位，讓使用者能透過 UI 設定 Epoch 等項目。

### 目前：實驗與文件彙整

- 將圖表依照時間、任務與階段整理到檔案室。
- 整理模型用途、輸入、輸出與實驗結果。
- 製作實驗時間軸簡報。
- 在簡報中標記部位辨識預訓練頁面，避免與皮膚病資料集混淆。
- 保留各階段的模型、設定、曲線與實驗紀錄，供後續論文與專題整理使用。

## 整體流程

```text
資料與授權整理
  ↓
第一階段基礎疾病模型
  ↓
第二階段正式疾病模型
  ↓
人體部位辨識預訓練（DensePose／COCO，非皮膚病資料）
  ↓
部位預訓練、ImageNet 與純淨模型比較
  ↓
多來源皮膚病資料混合訓練
  ↓
資料治理與跨來源泛化修復
  ↓
熱力圖檢查與基底模型篩選
  ↓
關卡式課程學習
  ↓
模型、訓練與熱力圖 UI 整合
```

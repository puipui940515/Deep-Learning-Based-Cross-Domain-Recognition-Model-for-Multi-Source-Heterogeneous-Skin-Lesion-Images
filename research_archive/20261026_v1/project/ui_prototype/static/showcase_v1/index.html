THE RESEARCH PROCESS

SkinDetect，實際怎麼訓練？

把資料、學習與評估分開，讓每一步都有清楚的用途。

  1. 01→

    整理與切分資料

    統一類別、檢查重複影像，區分 Train、Validation 與 Test。

    資料治理
  2. 02→

    用訓練集學習

    模型從訓練影像更新參數，學習影像特徵與類別之間的關係。

    模型訓練
  3. 03→

    用驗證集選模

    依驗證表現選擇模型，觀察跨來源差異；Test 保留作最終評估。

    Validation ≠ Test
  4. 04↗

    呈現與理解輸出

    顯示七類分布與限制，支援原 Seed1 及三 Seed 等權集成；GPU 一致性驗證另行記錄。

A NOTE BEFORE YOU GO

用來理解研究，不能代替診斷。

SkinDetect 是學生專題與研究展示，輸出不構成醫療建議。若對皮膚狀況有疑慮，請諮詢合格醫療專業人員。

請使用有權使用且已去識別化的影像。Mock 影像留在瀏覽器；真實推論才傳至這台電腦的本機服務，不保存影像或個案紀錄。分數尚未校準，不代表醫療診斷機率。

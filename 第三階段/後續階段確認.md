# 第三階段與後續階段確認

## 正式順序

1. 補完 v6–v9：每版 3 seeds，只依 validation 決策。
2. v10 空對照：四分支全為同一 RGB；骨幹與配方固定為 v9。
3. v11 雙視角：只把分支 2 改為色彩恆常性；基準為 v10。
4. v12 四視角：加入皮膚光學分解與多尺度帶通幅值；基準為 v10，並做逐視角 leave-one-out。
5. v12 後回頭複查：在最終架構對 v1–v12 已納入元件做 leave-one-out、3 seeds。
6. v13a 部位 label-only control：不改模型輸入，只啟用疾病內部的部位平衡 sampler。
7. v13b metadata：以 FiLM 融合部位、年齡、性別，並與 v13a 及 unknown-site 條件比較。
8. v14：溫度縮放、risk-coverage、TTA、類別空間圖；最後才單次解封 test。
9. 延伸 E-1：v14 模型在 PAD-UFES-20 做分佈外評估，不重訓。
10. 延伸 E-2：取得具有效膚色標註的 DDI 後才執行。
11. 延伸 E-3：ISIC 自監督預訓練，必須排除 HAM10000 test 影像。

從 v10 起，部位標籤已跟隨正式 train／validation batch 並產生分部位指標，但 v10–v12 不使用部位作模型輸入或 loss，避免破壞既有單變因順序。

## Gate

| Gate | 通過條件 | 未通過時 |
|---|---|---|
| 進入 v10 | v9 三種子 checkpoint/result 齊全；固定切分與部位 manifest 一致；validation gate 與顯存 smoke test 通過 | 禁止正式 v10 |
| 進入 v11 | v10 三種子完成並建立相對 v9 的空對照結論 | 禁止宣稱視角資訊收益 |
| 進入 v12 | v11 相對 v10 的提升大於種子標準差 | 無效視角不納入 |
| 進入 v13a | v12 消融與回頭複查完成，只保留有效視角 | 不啟用部位平衡 sampler |
| 進入 v13b | v13a 三種子完成，建立 label-only 對照 | 不把 metadata 效益與 sampler 效益混在一起 |
| 進入 v14 | 架構、超參數、metadata 與校準方法已由 validation 固定 | test 繼續封存 |

## 目前判定（2026-08-23）

- v9 三種子未完成，正式 v10 尚未解鎖。
- 部位標籤 manifest、batch 欄位、分部位指標與 v13a sampler 基礎已建立。
- v10 程式仍先做非實驗性 smoke test；v11／v12 不提前產生未驗證結果。

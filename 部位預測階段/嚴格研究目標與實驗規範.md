# 部位知識預訓練：嚴格研究目標與實驗規範

## 1. 唯一主要研究問題

預先以「解剖部位辨識」任務訓練過的影像骨幹，是否能在後續皮膚疾病分類中，提供比一般 ImageNet 初始化更好的辨識能力？

本研究檢驗的是**部位監督所形成的表徵是否可轉移**，不是在疾病模型推論時額外輸入部位標籤、部位機率或其他中繼資料。

## 2. 主要假設

- H1：真實部位標籤預訓練的模型，後續疾病分類 Balanced Accuracy 高於 ImageNet 初始化模型。
- 關鍵反證：若真實部位標籤組無法勝過「相同影像、相同訓練量、但部位標籤隨機打亂」組，則不能把提升歸因於模型學會了解部位。

## 3. 固定實驗組

| 組別 | 初始化方式 | 用途 |
|---|---|---|
| A：ImageNet baseline | 直接使用 ImageNet 預訓練權重 | 疾病分類基準線 |
| B：True-site pretraining | 使用外部皮膚影像及真實解剖部位標籤預訓練 | 主要實驗組 |
| C：Shuffled-site control | 與 B 完全相同，但全域打亂部位標籤 | 排除額外影像、訓練步數造成的提升 |
| D：Image-only control（選配） | 相同外部影像做自監督或無標籤預訓練 | 分離部位監督與一般領域適應效果 |

部位預訓練完成後，必須移除部位分類頭並重新隨機初始化疾病分類頭。疾病訓練與推論期間不得輸入部位標籤或部位預測。

## 4. 嚴格限制

1. 部位預訓練資料不得包含下游疾病驗證集或測試集影像；主要實驗優先採完全外部資料集。
2. 部位資料按受試者切分，不能讓同一人出現在 train、validation 或 test 的不同集合。
3. A、B、C、D 必須使用相同骨幹、疾病資料切分、影像前處理、增強、批次、最佳化器、學習率策略、epoch、早停規則與隨機種子。
4. 主實驗若接續第二階段 ConvNeXt-Tiny，部位預訓練也必須使用 ConvNeXt-Tiny；ResNet18 結果只能與相同架構的疾病基準比較。
5. 至少執行 3 個固定種子，並保存每張測試影像的預測，不能只報告最佳一次。
6. 模型與超參數選擇只看 train/validation；所有方案凍結後，才能開啟一次封存測試集。
7. 不得把先前「部位機率融合」結果當成此假設的證據；該實驗屬於不同方法，只保留為旁支結果。
8. 授權不明、影像來源不清、無法確認受試者切分或與下游資料重疊的資料，不納入正式實驗。
9. 不以跨架構、跨資料量、跨訓練時數的數值差異宣稱部位知識有效。

## 5. 評估指標與判定

- 主要指標：疾病分類 Balanced Accuracy。
- 次要指標：macro-F1、accuracy、ECE、各疾病 recall、confusion matrix。
- 主要比較：B 對 A，以及 B 對 C；只勝過 A、不勝過 C，不能證明是部位標籤帶來的效果。
- 報告三個種子的平均、樣本標準差及每個種子的配對差值。
- 封存測試集使用影像層級 bootstrap 估計 95% 信賴區間。
- 嚴格採納條件：B 對 A 與 C 的平均 Balanced Accuracy 都為正、至少 2/3 種子方向一致，且封存測試的主要差值 95% 信賴區間不跨 0。若未達成，結論應為「目前沒有足夠證據」，不是宣稱無效。

## 6. 分階段閘門

1. **G0 資料審核**：來源、授權、下載版本、雜湊、受試者 ID、標籤定義全部完成。
2. **G1 部位任務成立**：真實標籤組明顯勝過 shuffled 組，並完成跨來源或背景干擾檢查。
3. **G2 下游開發集比較**：A/B/C 使用相同設定完成 3 種子訓練。
4. **G3 凍結決策**：鎖定程式、checkpoint 選擇規則、指標及統計方法。
5. **G4 一次性正式測試**：解除封存測試集並產生最後結論。

## 7. 捷徑學習檢查

部位模型可能只記住攝影背景、拍攝角度、衣物或資料來源，而非人體部位，因此至少要做：

- 受試者層級切分。
- 真實標籤與 shuffled-label 對照。
- 跨資料來源的部位辨識測試。
- 遮蔽背景或裁切尺度敏感度測試。
- 檢查各部位是否與特定疾病或資料來源高度綁定。

## 8. 現有結果的定位

- `部位預測階段`既有四來源模型是短 epoch 探索性模型，且曾使用 HAM10000，不是本研究的正式外部預訓練模型。
- `第二階段/部位模型接續實驗`使用部位機率融合，回答的是「加入中繼特徵是否有用」，並非本文件的「部位監督預訓練是否改善初始化」。
- 正式主線應重新建立外部部位資料、匹配控制組與封存測試流程。

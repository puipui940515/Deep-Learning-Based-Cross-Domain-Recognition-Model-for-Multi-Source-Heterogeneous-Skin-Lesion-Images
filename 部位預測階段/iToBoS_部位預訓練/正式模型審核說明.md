# 正式部位模型審核說明（尚未訓練）

## 模型結構

正式模型改為與第二階段 v8 相容的 ConvNeXt-Tiny：

```text
RGB 影像 3×384×384
  ↓
Stem：4×4 Conv, stride 4, 3→96 + LayerNorm
  ↓
Stage 1：3 個 ConvNeXt Block，96 channels
  ↓
Downsample：2×2 Conv, stride 2
  ↓
Stage 2：3 個 ConvNeXt Block，192 channels
  ↓
Downsample
  ↓
Stage 3：9 個 ConvNeXt Block，384 channels
  ↓
Downsample
  ↓
Stage 4：3 個 ConvNeXt Block，768 channels
  ↓
Global Average Pooling
  ↓
LayerNorm + Flatten
  ↓
Linear 768→5
```

每個 ConvNeXt Block 使用 7×7 depthwise convolution、LayerNorm、4 倍通道擴張的 pointwise MLP、GELU、Layer Scale 與 residual connection。

## 相較先導模型的修改

| 項目 | Pilot | 正式候選 v1 |
|---|---|---|
| 骨幹 | ResNet18 | ConvNeXt-Tiny |
| 輸入 | 224×224 | 384×384 |
| 分類頭輸入 | 512 | 768 |
| Batch | 32 | 8，累積 4 次，effective batch 32 |
| Epoch | 1 | development 最多 30，patience 7 |
| Optimizer | AdamW | AdamW + layer-wise LR decay 0.7 |
| Scheduler | 無 | Cosine annealing |
| 左右翻轉 | 禁止 | 允許，但同步交換 left/right 標籤 |
| 垂直翻轉 | 禁止 | 禁止 |
| 評估 | train 內影像切分 | develop → 全 train refit → 一次性官方 test |

## 嚴格流程

1. **Develop**：只使用官方 train，固定 10% 影像層級 validation，選擇 epoch。公開資料沒有 patient ID，因此此數值不能作正式泛化結論。
2. **Refit**：將 develop 選出的 epoch 凍結後，使用全部官方 train 重新訓練。
3. **Test**：程式要求明確解鎖字串，並為每個 label mode／seed 建立單次使用 lock；官方 test 只評估一次。
4. 真實標籤與 shuffled-label 控制組必須使用相同設定與 seeds 17、42、2026。
5. 正式目標是官方受試者互斥 test Balanced Accuracy ≥ 0.90，且每類 recall ≥ 0.85；不以一般 accuracy 單獨判定。

## 防止爭議的程式限制

- 設定目前為 `awaiting_user_review`，程式會拒絕啟動訓練。
- 官方 test 預設封存，沒有特定解鎖字串不能讀取。
- 同一 label mode／seed 開啟 test 後留下 lock，禁止重複測試。
- checkpoint 記錄架構、影像尺寸、label mode、seed、epoch 與部位類別。
- 水平翻轉會同步交換左右手臂／腿標籤，不產生錯標。
- Unknown 排除，不自行猜測部位。

## 尚未保證的事項

此修改提高模型容量、解析度與訓練完整性，但不能事先保證官方 test 超過 90%。若一次正式 test 未達 90%，不能反覆使用同一 test 調參；應增加新的外部 validation 資料或重新設計預先註冊的實驗版本。

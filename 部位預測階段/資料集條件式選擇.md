# 部位預測資料集條件式選擇

## 納入必要條件

資料集必須同時符合：

1. 有逐影像或逐病灶的明確解剖部位標籤。
2. 可用病患、病灶或 case ID 做 group-level 切分，避免同一對象跨 train／validation。
3. 本地影像與 metadata 能一對一核對。
4. 授權允許研究與論文使用，且能完成來源標示。
5. 標籤可以無歧義映射到共同 schema；無法映射者排除，不強行猜測。
6. 不使用 test 進行訓練、早停或模型選擇。

## 目前決策

| 資料集 | 影像型態 | 部位標籤 | 決策 |
|---|---|---|---|
| HAM10000 | 皮膚鏡 | 單一 anatom_site | 已完成基線 |
| BCN20000 | 皮膚鏡 | 單一 anatomical site | 下一個正式 profile |
| PAD-UFES-20 | 手機臨床照 | 單一 region | 獨立 clinical profile，不直接混入皮膚鏡 |
| SCIN | 一般臨床照 | self-reported 多部位 | 獨立 multi-label profile；本地影像完整前不正式訓練 |
| ISIC Archive 疾病查詢子集 | 皮膚鏡／混合 | anatom_site | 暫不納入；疾病查詢造成部位與疾病混雜，且需逐張授權與重複稽核 |

## 共同五類映射

- head_neck
- trunk
- upper_extremity
- lower_extremity
- anogenital

BCN20000 的 `palms/soles` 同時包含手掌與腳底，無法唯一映射到上肢或下肢，因此在五類 profile 中排除。空白部位同樣排除。官方 test 保持封存；只將官方 train 依 lesion 分組建立內部 train／validation。

## 實驗順序

1. HAM-only：已完成。
2. BCN-only：同影像域、較大資料量，作為下一個主要實驗。
3. HAM+BCN：只有在 BCN-only 完成後才測試，並檢查來源不平衡及跨資料集泛化。
4. PAD／SCIN：改成 clinical-image 分支，不與皮膚鏡結果直接宣稱可比。

## 目的
E128 第一版範例圖顯示，照原論文式設定（β=0.01，在 384 像素下視窗半徑 3，即 7×7，整個換掉）會在影像上造出假的深色團塊與大片色斑。要比較幾種視窗大小與混合比例，找出只改整體色調、不製造假結構的設定。

## 做法
- 同一組影像（8 張）、同一張參考影像，比較四種設定：半徑 3 全換（原設定）、半徑 1 全換、半徑 1 混合 λ=0.5、半徑 0 全換（只換直流＝各通道平均亮度）。
- 量化：輸出與原圖的差異能量中，屬於中尺度結構（σ 4–24 像素）的比例，取 8 張的中位數（執行紀錄稱為「中尺度結構雜訊比例」）。
- 輸出比較圖 `E129_低頻互換設定比較.png`。
- 以 `e129_update_fda_run.py` 只修改 R2-HC-S20-FDA 這一個 run 的設定（該 run 從未啟動，可以改），其餘 run 逐字不變（腳本內斷言）。

## 結果

| 設定 | 中尺度結構比例（中位數） |
|---|---|
| 半徑 3 全換（原設定） | 0.026 |
| 半徑 1 全換 | 0.005 |
| 半徑 1 混合 λ=0.5 | 0.005 |
| 只換平均色（半徑 0） | 0.000 |

設定變更：

| | 舊 | 新 |
|---|---|---|
| R2-HC-S20-FDA | fda_prob 0.5、fda_beta 0.01（半徑 3，整個換掉） | fda_prob 0.5、fda_radius 1、fda_lambda_max 1.0（λ~U(0,1) 混合） |

## 推論
- 改成半徑 1、λ~U(0,1) 混合。E128 對新設定驗證：視窗內振幅符合 (1−λ)原 + λ參考（相對誤差 0.0011），視窗外中位數相對變化 0.0002。
- 後來 E132：此設定的 FDA 短跑（seed 17）最佳 ep19 val_select worst 0.6661（基準 0.6715）；PAD 後 10 epoch 平均 +1.47pp（10/10 為正），seed 42 複製 PAD +1.97pp（10/10），兩個 seed 方向一致。

## 限制
- 只看 8 張影像、一張參考影像；屬目視與簡單量化，不訓練。
- 只比較了四種設定，未掃描其他半徑或混合比例。
- （整理者註）腳本 docstring 寫量化的是「大尺度（高斯模糊 σ=24 後）的比例」，實際輸出文字與執行紀錄寫的是「中尺度結構（σ 4–24 像素）」，本頁依執行輸出的說法。

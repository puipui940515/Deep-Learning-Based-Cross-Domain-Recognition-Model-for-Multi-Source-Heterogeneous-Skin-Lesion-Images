# E119　磁碟盤點與清理（A 級清理、未引用 .tif 清理、DensePoseCOCO 刪除）

- 日期：2026-11-11（～2026-11-12）
- 狀態：完成（每一步刪除都經使用者回覆同意；SCIN 未動）
- 相關：起因為 E117 缺陷 D2（磁碟剩 13G）與計劃 2

## 目的
使用者要求清理不會用到的紀錄與存檔，釋放磁碟空間；前提是不能動到正在訓練的 seed 42、已完成 run 的結果與任何資料治理檔案。

## 做法
1. 盤點（零刪除）：列出可刪項目，分 A 級（可重建或已無用途）與 B 級（大型但需判斷），以及「不會動的」清單。
2. A 級清理（使用者回覆「只刪 A 級」）：腳本預設只核對，加 `--apply` 才刪。刪除前保護：zip 內每張影像必須在解壓目錄找到同名同大小檔案；任何路徑落在訓練中的 seed 42 目錄就整個中止；last.pt 只刪「同目錄有 result.json 且有 best.pt」的；config.json 與執行中行程的命令列不得引用任何待刪檔。
3. B 級逐項詢問：DensePoseCOCO 兩個 zip（使用者回覆可刪）；未引用的 ISIC .tif 先查身分再依使用者回覆「保留一點」處理（規則由助理解讀：每個診斷類別依檔名排序前 2 張各留一份，被 manifest 引用的 5 張不動）。

## 結果

盤點（2026-11-11）：

| 級別 | 項目 | 大小 |
|---|---|---|
| A | 已解壓的資料集 zip 3 個 | 11.61 GB |
| A | smoke_results（冒煙測試輸出）42 個檔 | 0.74 GB |
| A | 已完成 run 的 last.pt 4 個 | 2.21 GB |
| A | 中斷且無法續跑 run 的 .pt 5 個 | 0.92 GB |
| B | 三份 manifest 都沒引用的 ISIC .tif 118 個 | 22.96 GB |
| B | DensePoseCOCO 兩個 zip | 18.77 GB |
| B | SCIN 資料集（D3 評估過、未採用） | 0.97 GB |

執行：
- A 級：三個 zip 內影像（BCN train 12,413、BCN test 6,501、HAM 10,015）逐張核對缺 0 張；共刪 15.48G；C 槽可用 22.49G → 37.98G。
- DensePoseCOCO：兩個 zip 刪除，C 槽可用 46G → 65G。
- 未引用 .tif 身分查證：118 個檔只有 76 張不同影像（42 張在兩個 ISIC 目錄各存一份，純重複 8.27G）；76 張的 image_type 全是「RCM: mosaic」（反射式共軛焦顯微鏡拼接圖），不是皮膚鏡也不是臨床照。
- .tif 清理：保留 8 個（1.62G），刪除 110 個（21.33G），失敗 0；C 槽可用 64.07G → 85.41G。刪掉的都能用 ISIC id 從 ISIC Archive 重新下載。
- seed 42 在每次刪除後都仍在跑。

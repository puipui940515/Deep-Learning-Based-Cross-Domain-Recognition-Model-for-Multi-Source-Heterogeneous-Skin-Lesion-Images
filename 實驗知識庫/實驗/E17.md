# E17　現在的問題真的是過擬合嗎？用多模型錯誤重疊來分辨

- 日期：2026-11-02
- 狀態：完成；結論由 E18 直接檢驗並成立，寫成 ADR 0004；「棄權救不了」後來被 E38 加上條件
- 相關：前置 E5（訓練集擬合）、E10、E15；細項 E17b（val_select 拆解）、E17c（val_assess 重做）；後續 E18、E19、E21、E38、E80；ADR 0004

## 目的

E5 量到大落差（訓練 recall 0.935–1.000、驗證 0.509–0.906），但「落差大」本身分辨不了成因。E15 整理過至少有記憶、捷徑、分布位移，再加上「影像本來就分不出來」四種成因，處方完全不同。使用者提問「現在的問題是不是過擬合」，本實驗用既有 logits 做能分辨成因的檢定，不需要 GPU。

## 做法

- 判準：過擬合（變異意義）預測「不同模型錯在不同影像上」；若錯在同一批，就是系統性錯誤，正則化無效。
- 六個模型：R0 s17／s42、R0-BAL s17／s42、R1 s17、R2 s17（2 種子、2 種取樣指數、3 種解析度、2 種骨幹）。
- 主要數字在 val_assess（9,652 張，從未參與早停或選檢查點）上算，排除「大家用同一集合挑模型才使錯誤相關」的假象；val_select 上也做了一次（E17b）。
- 四個檢定：(1) 全錯張數 vs 獨立犯錯虛無預期、兩兩 lift = P(B錯｜A錯)/P(B錯) 與其上限；(2) R2 錯誤拆解；(3) 信心剖面；(4) 共錯的混淆方向。

## 結果

| 項目（val_assess） | 數值 |
|---|---|
| 六模型全錯 | 760 張（7.87%） |
| 獨立犯錯虛無預期 | 0.5 張（json：0.53） |
| R0(tiny@224) 對 R2(small@384) 的 lift | 3.78（上限 5.5，達 69%） |
| 所有配對 lift 範圍 | 3.4–4.0 |
| R2 錯誤數／錯誤率 | 1,763 張／0.1827 |

R2 錯誤拆解：

| | 張數 | 佔 R2 錯誤 |
|---|---|---|
| 六模型全錯 | 760 | 43.1% |
| ≤2 個模型錯（像變異） | 281 | 15.9% |
| 3–5 個模型錯 | 722 | 41.0% |

若共錯修不好，準確率天花板 0.9213，R2 現為 0.8173，空間 10.39pp。

| 平均信心 | |
|---|---|
| 答對 | 0.861 |
| 六模型全錯 | 0.768 |
| 只有自己錯 | 0.666 |

共錯前幾組：MEL→NV 96（12.6%）、NV→MEL 83（10.9%），雙向合計 23.6%；其後 AKIEC→BCC 41、BKL→AKIEC 39、BKL→BCC 39、BKL→NV 34、NV→BCC 32、BKL→MEL 31。

val_select 上數字幾乎一樣：共錯佔 R2 錯誤 44.0% vs 43.1%，lift 3.84 vs 3.78。

## 推論

- 不是過擬合，至少不是主要的：過擬合最多只解釋 R2 錯誤約六分之一。排序為系統性（約 43%）、中間地帶（約 41%）、變異／過擬合（約 16%）。
- 共錯那批信心高，代表模型學到明確但錯誤的規則，不是沒學夠；因此棄權救不了。
- MEL↔NV 雙向對稱是真實視覺重疊的特徵（單向才像捷徑）；BKL 往四面八方散，像標籤本體問題。
- 模型端介入（R2-REG、R2-LONG）的上限就是那 10.39pp；能動 43% 的是資料端：標籤本體（AKIEC 的 662 張 SCC in situ、family 桶）、捷徑（墨跡、來源指紋），以及誠實量出 MEL↔NV 的天花板。

後續修正與檢驗：
- E18（同日）：R2-REG 只修掉 760 張中的 42 張，預測成立。
- E19（同日）：本頁推薦的兩條資料端方向——「family 桶」與「AKIEC 裡的 SCC in situ」——被自己的數據推翻（family 與類別共線；SCC in situ 錯誤率與日光性角化症相同）。
- E38（2026-11-04）：重算共錯集得 760 張，與 E17c 完全一致；但換成九個模型等權平均的信心，答對與共錯的差距是 0.167（R2 自己是 0.093），按集成信心棄答時共錯被棄得更兇，所以「棄權救不了」只對 R2 自己的信心成立；「修不了」仍成立（集成在 760 張上只修對 1 張）。
- E80（2026-11-07）：非 ConvNeXt 的 swin_t 只修掉 760 張中的 61 張（8.0%），落在 ConvNeXt 對照 5.0–13.7% 之內，紀錄判定 43% 共錯率不是 ConvNeXt 的產物，ADR 0004 不用重寫。

## 限制

- 六模型共用同一批訓練資料、標籤本體、前處理、ImageNet 預訓練與 ConvNeXt 家族；只證明「不是換種子／骨幹／解析度能解決的」，沒證明換資料、改標籤定義或拿掉捷徑也解決不了。
- 當時沒有非 ConvNeXt 的模型（後由 E80 補上）。
- 共錯沒有拆成「標籤錯」與「真的難」，需要皮膚科醫師盲判。
- R0 s42、R0-BAL s42 只跑 7–8 個 epoch 就早停，訓練程度不如 seed 17。
- 單一 val_assess 切分，沒有重抽。

## 前因與後果

**前因**
- 引發｜[E15](E15.md)（過擬合的成因：文獻清單（按機制分類，逐項對照本專題現況））：E15 區分不同成因與處方，促使 E17 用共錯檢定辨別成因。
- 支持｜[E17b](E17b.md)（E17 的 R2 錯誤拆解（val_select 版）與）：val_select 與 val_assess 共錯比例相近，支持 E17 排除選模假象。
- 支持｜[E17c](E17c.md)（val_assess 上的六模型共錯集（E17 主結論的）：E17c 提供未參與選模的共錯數據，支撐 E17 主結論。
- 支持｜[E18](E18.md)（R2-REG：加強正則化（mixup 0.8 + ran）：正則化只修掉 760 張中的 42 張，符合 E17 的共錯難動預測。
- 支持｜[E36](E36.md)（2026-11-04 自主時段：事先登記與免訓練集成家族）：E36 整理集成幾乎修不了共錯，支持 E17 對系統性錯誤的判斷。
- 支持｜[E80](E80.md)（事先登記：swin_t 的錯誤與「六個 ConvNeXt）：非 ConvNeXt 模型仍難修共錯，支持 E17 結論不限於同家族模型。
- 推翻或更正｜[E19](E19.md)（那批共錯，是不是驗證集自己的問題？）：E19 發現類別共線與相同錯誤率，推翻 E17 推薦的兩條資料方向。

**後果**
- 引發｜[E70](E70.md)（類別內異質性：「同一類裡裝太多種」是不是錯誤的原因）：因為 E17 的最大錯誤區塊含非 family 的 NV，所以 E70 直接檢驗異質性解釋。

- 支持｜[E21](E21.md)（目前的問題總結（收攏 E5、E10–E20））：E17 的共錯與混淆結果支撐 E21 A1、A3 的問題總結。
- 推翻或更正｜[E10](E10.md)（表現差的類別，除了資料量以外差在哪（R2 的 val_a）：E17 的共錯檢定推翻 E10 的教科書式過擬合解釋。

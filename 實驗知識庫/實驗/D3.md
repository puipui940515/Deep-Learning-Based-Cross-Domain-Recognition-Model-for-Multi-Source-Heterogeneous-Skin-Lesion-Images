# D3　新資料集與 YOLO 偵測裁切的可行性查核

- 日期：2026-11-01
- 狀態：完成（文件內含 2026-11-01 的自我更正）
- 相關：前置 D2、R0（G-R0 病灶框未通過）、B2；後續 E1、E6（遮罩覆蓋盤點）、E7（偵測器）

## 目的
D2 顯示 R1 召回最低的是 AKIEC 50.9 與 SCC 52.2，SCC 誤判有 43.8% 落在 BCC 與 AKIEC。使用者表示可以接受引入新資料集、可以考慮 YOLO。要查核：哪些外部資料能修哪個缺陷、YOLO 能解決什麼、協定上的後果是什麼。

## 做法
- 只做查核，沒有下載任何影像、沒有改 manifest。
- 實際下載 `fitzpatrick17k.csv`（metadata，4.0 MB）清點，不憑印象。
- 查 DDI 的取得條件；檢查專案現有病灶框 `bbox_D2` 的可用性；查公開的人工病灶遮罩。

## 結果
**Fitzpatrick17k（建議採用）**：16,577 筆中能對上八類的有 2,010 張，其中 SCC 581（Fitzpatrick 4–6 深膚色 134）、BCC 468＋62、MEL 261＋118＋111、AKIEC 175、NV 86、DF 79、BKL 69。授權 CC BY-NC-SA 3.0（非商業）；影像需從兩個第三方網站抓（1,420＋584 張，6 筆無 URL，部分連結失效）；`qc` 只有 60 筆有醫師標註，其中 2 筆標為標錯；臨床照，會擴大域差異。

**DDI**：656 張、570 位病人、病理確診、以深膚色為主，需簽研究用途協議。建議當第三方驗證集，不進訓練。

**ISIC 內其他 collection**：優先度最低。

**YOLO**：
- 不解決 85% 逐類準確率；可能間接有用的路是「偵測 → 緊貼病灶裁切 → 分類」，拿掉孔徑、病灶佔畫面比例等來源特徵（依據 A 系列稽核與 R1 逐來源差距 BCN 58.56／ISIC 66.24／HAM 79.75／PAD 84.88）。
- `bbox_D2` 的 86,534 個框是啟發式的，人工複核未通過（R0_visual_review：human_approved=false），拿來訓練 YOLO 等於蒸餾錯誤，不可用。
- 人工遮罩：ISIC 2018 Task 1（2,594 張、CC0、26.1 MB）；另找到 HAM10000 tschandl 遮罩（10,015 張，命中 manifest 8,511 張，網路產生後由一位皮膚科醫師逐張修正）。兩組合計 11,091 張（佔 manifest 12.8%），偵測器 train 集 8,002 張。
- 遮罩覆蓋率：HAM10000 100%、ISIC_Archive_Expanded 4.0%、BCN20000 0%、PAD-UFES-20 0%、SCC 0%。

建議順序：1) ISIC 2018 遮罩 → 類別無關偵測器 → 偵測裁切（不改 manifest，可直接與 R2 比）；2) Fitzpatrick17k 2,010 張併入訓練；3) DDI 當外部驗證。

## 推論
- Fitzpatrick17k 直接修掉「SCC 只存在於一個來源」的缺陷；AKIEC/SCC 是標籤體系劃的邊界，新資料修不了。
- YOLO 只能做類別無關的病灶偵測器，而且偵測器只學皮膚鏡影像，套用到 BCN 與 PAD 時品質無法量化驗證；BCN 偏偏是表現最差的來源。唯一的關卡是視覺稽核，而同一關卡上次否決了 `bbox_D2`。
- 協定後果：併入第五個來源會改變 `manifest_sha256`，既有 R0／R1／R2 從此不可直接比較；源等權從 1/4 變 1/5；封存測試集不重切。
- **2026-11-01 更正（文件內已加註）**：原本寫「ISIC 2018 Task 1 的影像衍生自 HAM10000」是錯的。實際下載比對後，遮罩全部落在 ISIC_Archive_Expanded（2,580 張命中），HAM10000 一張都沒有，且只涵蓋 NV 1,858、MEL 514、BKL 208 三類。執行紀錄記為助理第五次拿錯前提，這次在下載比對時抓到。
- 同日另發現一個既有缺陷：`train.py` 先做 `Image.draft` 降採樣，而 `bbox_D2.json` 存的是像素座標且無參考尺寸，框會指錯位置；處置為 `geometry.crop` 新增正規化座標分支。

## 限制
- 只查 metadata 與官方頁面，沒有下載影像；Fitzpatrick17k 標籤多數來自圖譜說明文字，非病理確診。
- 偵測器在 BCN／PAD 上的品質無法用量化指標驗證。

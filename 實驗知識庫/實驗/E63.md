# E63　特徵檯 v2：補上 C 類（表面起伏／陰影線索）

- 日期：2026-11-05
- 狀態：完成（取代 E61）
- 相關：前置 E61、E62；後續 E64（C 類的針對性檢定）、E65（真的深度模型）

## 目的
E61 沒收 C 類，理由是「接觸式皮膚鏡把表面壓平」；E62 看圖後這個說法站不住（部分影像有明顯鏡面高光與邊緣投影）。所以把 C 類加上特徵檯，看它在 RGB 之外有沒有新的類別資訊。

## 做法
- 與 E61 相同的檯子：每個候選抽全域統計量 → 梯度提升樹預測八類 → worst_source_macro_f1_ge30；報單獨分數與「＋RGB」的增量。
- 新增 C 類：不用單目深度模型（MiDaS 需要 timm，且在自然場景訓練、用於皮膚鏡特寫屬分布外），改為直接量物理線索——鏡面高光、邊緣投影、徑向亮度剖面、亮度平面殘差、梯度方向的偶極性。
- 縮圖 160；訓練 9,866 張、val_select 12,102 張評分；seed 20261105。val_assess 讀 0 次。

## 結果
RGB 基線 0.2895（最差來源）。

| 家族 | ＋RGB 增量 (pp) |
|---|---|
| E 元資料 | +4.55 |
| A4 Lab a*/b* | +1.90 |
| D 框形態 | +1.87 |
| B2 LBP | +1.45 |
| A3 極端對比 | +1.01 |
| B3 DoG | +0.88 |
| A2 CLAHE | +0.83 |
| **C 表面起伏／陰影** | **+0.81** |
| B1 Sobel | +0.30 |
| A1 色彩恆常性 | +0.14 |

C 類：單獨最差來源 0.2340、＋RGB 0.2976。全部合併：最差來源 0.3910（+10.15pp）、macro-F1 0.4163、準確率 0.6138。加入 C 讓全家桶從 0.3876（E61）升到 0.3910（+0.34pp）。

## 推論
- C 類增量 +0.81pp，排第八。
- 但這個檯子對 C 特別不公平：表面起伏是局部空間性質（高光在中央、陰影在邊緣），樹模型吃的是全域統計量。所以 C 的低分**不能**當成「深度沒用」的定論，只能說「以全域統計量來看沒有超出顏色」。因此接著做 E64 的針對性檢定與 E65 的單目深度模型。

## 限制
- 樹模型與 CNN 不等價，本檯只排序候選、不預測訓練成果。
- 單一 seed、子抽樣訓練集。

# E58　用本機 Codex 逐張標記 PAD-UFES-20 全部 834 張「有沒有醫師墨跡」

- 日期：2026-11-05
- 狀態：完成（標記被 E59／E59b 使用；標記是 Codex 判讀，不是真值）
- 相關：前置 E57（顏色篩選器）；同步 E58b（不一致抽查）；後續 E59、E59b；連帶修正 E11b／E11c 的墨跡率

## 目的
E57 的顏色篩選器標出 96/834＝11.5%，與 E11c 人眼的 11.7% 幾乎一樣，但總量吻合不代表逐張吻合，必須逐張驗。「有沒有墨跡」是是非題，比 E52 的「框在哪」容易得多，所以 Codex 在這個任務上可以當作夠好的第二意見（不是真值）。使用者當天暫時解除 Codex 用量限制，因此直接標完全部 834 張，而不是只抽樣驗篩選器。

## 做法
- 範圍：PAD-UFES-20 的 val_select（613 張）＋ val_assess（221 張）。
- 模型 gpt-6-astra、effort high；影像縮到長邊 512；每批 20 張送一次 `codex exec`，`--output-schema` 逼出逐張 true/false；read-only sandbox。
- 問題：這張有沒有醫師用筆畫在皮膚上的墨水痕跡？
- 輸出：逐張標記、與 E57 篩選器的混淆矩陣、不一致清單。
- 只讀影像，不訓練、不碰 GPU；val_assess 讀 0 次（只產生標記，不算成績）。

## 結果
42 批全成功，834/834 張都有標記。

| 範圍 | n | Codex 標為有墨 |
|---|---|---|
| 全部 | 834 | 272（32.6%） |
| val_select | 613 | 207 |
| val_assess | 221 | 65 |

與 E57 顏色篩選器的混淆矩陣（以 Codex 為參照）：

| | Codex 有墨 | Codex 無墨 |
|---|---|---|
| 篩選器有墨 | TP 72 | FP 24 |
| 篩選器無墨 | FN 200 | TN 538 |

篩選器精確率 0.75、召回率 0.265，兩者一致率 73.1%。

## 推論
- Codex 標出的墨跡率（32.6%）是顏色篩選器（11.5%）的三倍。
- E58b 目視抽查：篩選器的低召回率是真的（淡紫細線被漏掉）；FP 組 8 張都沒有筆跡，Codex 在那組判對，所以它不是見黑影就喊。
- **連帶修正**：E11b 的 15.6%、E11c 的 11.7% 都是在每格約 330px 的接觸表上判讀，漏的正是淡紫細線，可能偏低；已在 E11c 的 JSON 加註 `_superseded_note_20261105`。
- 但也不能直接採信 32.6%：FN 組 8 張只有 3 張確認是墨，若 200 張 FN 只有約四成是真的，實際約 (72+80)/834 ≈ 18%。E59 報告的說法：PAD 的墨跡率在 11.5% 到 32.6% 之間，抽查指向 18% 上下，比 E11／E11c 報的高；要釘住需要一次分層的人工標註。

## 限制
- Codex 標記不是真值；E59 估計 272 張裡可能有三到四成是誤報。
- 只涵蓋 PAD 的 val_select／val_assess，不含 train。

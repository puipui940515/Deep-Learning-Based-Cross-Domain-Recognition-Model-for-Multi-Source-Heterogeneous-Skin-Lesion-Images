# ADR-0004　主要問題不是過擬合，而是多個模型錯在同一批影像上的系統性錯誤

- 日期：2026-11-02
- 狀態：完成（已定案，附可被推翻的條件；2026-11-07 首次被非 ConvNeXt 家族檢定並通過）
- 相關：前置 E5（訓練召回 0.935–1.000）、E17（共錯診斷）、E18（R2-REG 正則化）、E21（問題總結）；修正 E10 第 8.2 節「教科書式過擬合」的判讀；後續 ADR-0005（排除的解釋）、ADR-0007（集成）、E38（棄答）、E80／E89（swin 跨家族檢定）、E114／E115（訓練曲線與 ECE）

## 目的
E5 量到訓練召回 0.935–1.000、驗證召回 0.509–0.906，落差最大的 AKIEC 達 46.75pp，看起來是教科書的過擬合，「把落差壓下去」看起來就是處方。這份 ADR 要判定：驗證錯誤的主因到底是不是（變異意義上的）過擬合。

## 做法
- 判準：過擬合的核心預測是「不同的模型會錯在不同的影像上」。所以拿多個模型，看它們是否錯在同一批影像上。
- 全部在 val_assess 上算（從未參與早停或選檢查點）。
- 模型：E17 用六個（R0 s17／s42、R0-BAL s17／s42、R1 s17、R2 s17，涵蓋兩種子、兩種取樣指數、三種解析度、兩種骨幹）；E18／E19 加入 R2-REG 成為七個。
- 直接驗證：R2-REG（+ mixup 0.8 + erasing 0.25）能修掉多少共錯。

## 結果

| 項目 | 數值 |
|---|---|
| 七個模型全錯 | 718 / 9,652（7.44%） |
| 獨立犯錯的虛無預期 | 0.1 張 |
| R2 錯誤中「共錯」的比例 | 43.1% |
| R2 錯誤中「≤2 個模型錯」（像變異） | 15.9% |
| 準確率天花板（若共錯修不好） | 0.9213 vs 現在 0.8173 → 空間 10.39pp |
| 平均信心：共錯／只有自己錯／答對 | 0.768 ／ 0.666 ／ 0.861 |

R2-REG 的直接驗證（E18）：
- 只修掉 760 張（六模型）共錯中的 42 張（5.5%），逐張交換帳淨 −42 張。
- 選定指標 +1.30pp，bootstrap 區間含 0，小於換種子的噪音（1.68–3.69pp）。
- 訓練／驗證落差縮了 2.92pp，其中 78% 來自訓練召回下降；BKL 與 SCC 訓練召回顯著下降、驗證召回 ±0.00pp。

## 推論
ADR 的三項決策：
1. 不再把「縮小訓練／驗證落差」當目標；R2-REG 削掉的是 Feldman（STOC 2020）長尾理論所說的必要記憶，不是過擬合。
2. 不再投資棄權（abstention）：模型很確定地錯。
3. 模型端介入（換骨幹、解析度、正則化、延長訓練）的期望值一律訂在 10.39pp 以內。

後來的發展：
- 2026-11-04 E38（記在 ADR-0005 的修正）：用集成自己的最高分排序棄答，40% 覆蓋率下共錯留存率 7.6%、非共錯 42.8%；所以第 2 條要改成「對『修』成立，對『避』不成立」。ADR-0005 註明本 ADR 核心主張不受影響：集成整體 +1.59pp 全部來自非共錯那 8,892 張，共錯 760 張只修對 1 張。
- 2026-11-07 E80：swin_t（真正不同的家族）修掉那 760 張的 8.0%，落在同家族對照範圍 5.0–13.7% 之內；六個 ConvNeXt 加 swin 七個全錯 699 張（7.24%），天花板從 0.9213 抬到 0.9276（+0.63pp）。紀錄結論：「ADR-0004 不用重寫」，43% 共錯率不是 ConvNeXt 的產物。
- 2026-11-07 E89：swin_t@224 修掉 8.4%，與 384 版的 8.0% 幾乎相同，改解析度也沒有改變錯誤結構。
- E114（R2-REG-LONG，60 epoch）：train loss 單調下降、驗證指標 ep20 之後在 0.68–0.69 震盪而沒有下滑，紀錄寫「沒有古典的過擬合樣態」，與本 ADR 一致。E115 的 ECE 在前 3 個 epoch 後就雜訊震盪，紀錄更正為「相容，但不是印證」。

## 限制
- 七個模型全是 ConvNeXt，共用訓練資料、標籤本體、前處理與 ImageNet 預訓練；嚴格證明的只有「這 43% 的錯誤不是換種子／骨幹／解析度／正則化能解決的」，沒有證明換資料、改標籤定義、拿掉捷徑也解決不了（swin 檢定補上了家族這一軸，其他軸仍未碰）。
- 共錯沒有再拆成「標籤錯」與「真的難」（需要皮膚科醫師盲判）。
- R1／R2／R2-REG 都只有 seed 17。

## 前因與後果

**前因**
- 支持｜[E114](E114.md)（訓練曲線：train loss ＋ 驗證選模指標（專案沒）：E114 當時觀察驗證指標未持續下滑，支持主要問題非過擬合的判斷。
- 支持｜[E17](E17.md)（現在的問題真的是過擬合嗎？用多模型錯誤重疊來分辨）：E17 發現不同模型大量共錯，支持錯誤主要具有系統性的判斷。
- 支持｜[E18](E18.md)（R2-REG：加強正則化（mixup 0.8 + ran）：E18 加強正則化仍少有改善，支持縮小訓練驗證落差不是主處方。
- 支持｜[E19](E19.md)（那批共錯，是不是驗證集自己的問題？）：E19 的七模型共錯統計為 ADR-0004 的系統性錯誤判斷提供證據。
- 支持｜[E21](E21.md)（目前的問題總結（收攏 E5、E10–E20））：E21 彙整共錯與正則化證據，支持 ADR-0004 的主因判斷。
- 支持｜[E80](E80.md)（事先登記：swin_t 的錯誤與「六個 ConvNeXt）：不同家族的 Swin 也少能修掉共錯，支持系統性錯誤並非家族特例。
- 支持｜[E89](E89.md)（R2-SWIN224 判定：把 Swin 的視窗幾何修好）：Swin 改用 224 解析度仍未改變錯誤結構，支持原共錯判斷。
- 推翻或更正｜[ADR-0005](ADR-0005.md)（「七個模型為什麼錯在同一批影像上」已被排除的解釋清單）：ADR-0005 的棄答修正使 ADR-0004 不再能概括宣稱棄權無效。
- 推翻或更正｜[E38](E38.md)（「棄權救不了」與「棄答很有用」是不是矛盾（事後探索））：E38 證明集成信心能避開共錯，更正 ADR-0004 的棄權決策。

**後果**
- 引發｜[ADR-0005](ADR-0005.md)（「七個模型為什麼錯在同一批影像上」已被排除的解釋清單）：確立錯誤具有系統性後，ADR-0005 開始逐項排查候選解釋。
- 引發｜[ADR-0006](ADR-0006.md)（排除大部分解釋後，僅存的幾條有數字支撐的線索（SCC 取）：ADR-0004 限定模型端改善空間，促成對剩餘可操作線索的排序。
- 引發｜[ADR-0007](ADR-0007.md)（可操作的槓桿是集成（多個模型等權平均），不是換架構）：ADR-0004 確立模型端改善上限，促成後續尋找真正有效的介入。
- 引發｜[E77](E77.md)（Swin 當骨幹的可行性實測：VRAM、單步時間、lay）：因為 ADR-0004 要求不同家族檢驗共錯，所以 E77 先量 Swin 的實作可行性。
- 推翻或更正｜[E10](E10.md)（表現差的類別，除了資料量以外差在哪（R2 的 val_a）：共錯診斷與正則化驗證更正 E10 將主因歸為過擬合的解讀。
- 推翻或更正｜[E5](E5.md)（模型能不能擬合自己的訓練資料：訓練召回 vs 驗證召回）：共錯與介入結果更正 E5 將訓練驗證落差解讀為直接正則化處方。

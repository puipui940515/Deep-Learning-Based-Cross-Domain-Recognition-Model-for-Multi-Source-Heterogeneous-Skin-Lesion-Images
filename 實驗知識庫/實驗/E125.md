# E125　補下載的 252 張 ISIC 2018 測試影像與訓練資料的洩漏檢查

- 日期：2026-11-12（～2026-11-16 補記）
- 狀態：完成（發現 24 張同病灶；manifest 未修改，留待下一代 manifest 排除）
- 相關：前置 E123（排除各屆測試集的 manifest）、E100b（近似重複的雙門檻）；服務 E124（醫師對比的「剔除同病灶」版本）；E143 資料索引的 flags 表收錄本結果

## 目的
ISIC 2018 Task 3 測試集官方 1,512 張中，有 252 張（全部的 BKL 217、VASC 35）原本不在磁碟上。使用者同意補下載後，要確認這 252 張與 R2-REG-LONG-HC 所用 manifest 的 train/val_select/val_assess 有沒有洩漏。因為它們原本不在 manifest，E123 的同病灶、近似重複排除沒有涵蓋到它們。

## 做法
- 下載：來源 ISIC Archive（位址由官方 API collection 取得），CC-BY-NC，252 張共 7.78 MB，存於主 repo 的 `Dataset/ISIC2018_Task3_Test_補齊_2026-11-12/`（images 與含逐張 sha256 的 provenance.csv），只當測試用。
- 同病灶：252 張的 lesion_id（ISIC API 提供）是否出現在 manifest 的 lesion_id。
- 同一張實體影像：256-bit dHash 漢明 < 20 且 64×64 灰階標準化 RMS < 0.15（與 E100b 相同的雙門檻）。
- 重複比對範圍不是整份 manifest：HAM10000 來源全部，加上 ISIC_Archive_Expanded 中標成 BKL 或 VASC 的列；理由是這 252 張全是 600×450 的 HAM 系列影像、類別只有 BKL 與 VASC。
- 輸出供 E124 使用的清單，以 leak 欄標出被查到的影像；不修改任何 manifest。

## 結果

| 項目 | 數值 |
|---|---|
| 補下載影像 | 252（BKL 217、VASC 35） |

| 牽涉的 manifest 列 | 48 列（train 34、val_select 4、val_assess 10；標籤 BKL 38、VASC 10；全在 ISIC_Archive_Expanded） |
| 上述 48 列的不重複 record_id | 30 個（2026-11-16 補記） |
| 重複比對掃描列數 | 12,504 |
| manifest 存活列數 | 74,319 |
| 同一張實體影像 | 0 張 |

## 推論
- 補下載影像沒有與訓練資料是同一張影像的情況，但有 24 張與訓練／驗證資料屬於同一顆病灶。E124 因此算兩次（全部、剔除這 24 張）。
- 這 48 列未從 manifest 移除，留待下一代 manifest 排除（R2-REG-LONG-HC 正在用此 manifest 訓練，不能改）。
- 後來（2026-11-16 建資料索引時）更正：48 列其實是 30 個不重複 record_id。原因是 manifest 檔有含換行的欄位，用行數算列數會錯（整理者註：48 筆是「測試影像 × manifest 列」的配對數，同一列可能對到多張測試影像）。

## 限制
- 重複影像只比對了 HAM10000 全部與 ISIC 的 BKL/VASC 列，不是整份 manifest。
- 同病灶只依 ISIC API 提供的 lesion_id。
- 下載過程曾出錯：前兩次 252 張全被拒收，原因是用 API metadata 的 size 欄做驗證條件而它與實際檔案大小不一致，第二次則是取代指令沒生效就重跑；改為驗 JPEG 標頭、PIL 完整解碼、像素尺寸相符後 252/252 通過。
- 原紀錄寫該資料夾內有 README.md，後更正：寫入被工作樹保護擋下，說明檔改放在工作樹的 `模型改進/data/isic2018_task3_test_extra_images.README.md`。

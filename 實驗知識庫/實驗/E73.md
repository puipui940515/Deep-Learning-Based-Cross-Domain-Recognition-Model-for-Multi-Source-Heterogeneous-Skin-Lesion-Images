# E73　R2-FINE 是否進入停滯期：曲線加量化停滯判準

- 日期：2026-11-06
- 狀態：完成（判定「還沒停滯」）；R2-FINE 隨後被使用者停在 epoch 16，不是完成品
- 相關：前置 E71／E72（細分類）；判準後來被通用化為 E79

## 目的
使用者要求看 R2-FINE（細分類訓練，與 R2 只差 `fine_labels`）的曲線，判斷是否已進入停滯期。曲線本身不能判停滯：R2 自己在 ep10 掉到 0.6513、ep11 回到 0.6656、ep12 又掉到 0.6594，之後在 ep13–20 漲到 0.6845，所以「連續幾個 epoch 沒進步」在這條曲線上是常態。

## 做法
四個判準（指標 worst_source_macro_f1_ge30，val_select）：

1. 最後 k 個 epoch 的 OLS 斜率與 95% CI（k=5 與 k=8）；CI 含 0 → 看不出趨勢。
2. 距離 best 幾個 epoch。
3. R2 的同期參照：R2 在同一個 epoch 之後還漲了多少。
4. R2 歷史上最長「連續無進步」段，用來校準第 2 項。

不碰 GPU、不訓練、val_assess 讀 0 次。當時 R2-FINE 完成 12 個 epoch。

## 結果

| 項目 | 數值 |
|---|---|
| R2-FINE best | 0.6669 @ ep10，距 best 2 個 epoch |
| worst 斜率 k=5 | +0.284 pp/epoch，CI [-0.736, +1.304]，p=0.441 |
| worst 斜率 k=8 | +0.348 pp/epoch，CI [+0.063, +0.632]，p=0.0242（不含 0） |
| train_loss 斜率 k=8 | -0.014/epoch，p=2.5e-06 |
| BCN 的 BKL 斜率 k=5 | -0.795 pp/epoch，CI [-1.362, -0.229]，p=0.0209 |
| R2 在 ep12 | 0.6594，之後漲 +2.52pp 到 ep20 的 0.6845 |
| R2 最長無進步段 | 4 個 epoch（結束於 ep17） |
| R2-FINE 最長無進步段 | 2 個 epoch |

## 推論
- 當時判斷（助理標明「我的判斷，非結果」）：還不到停滯的證據門檻，建議讓它跑完 20 個 epoch。
- 但「BCN 的 BKL」這一格（事先指定為「拆開有沒有用」的判準，因為 BCN 那 1,124 張 BKL 沒有細標籤）近五個 epoch 在退。
- 後續：使用者在 2026-11-06 20:43 停止 R2-FINE，已完成 16 個 epoch、best 0.6799 @ ep16，沒有 result.json；使用者決定不續跑。結果目錄寫入「不是完成品、0.6799 不得對外引用」的說明。16 個 epoch 軌跡：0.5437、0.5899、0.6222、0.6231、0.6370、0.6477、0.6495、0.6593、0.6418、0.6669、0.6631、0.6629、0.6748、0.6773、0.6745、0.6799。對照 R2 完成品 ep20 = 0.6845（val_select）。
- 之後加入 Swin 骨幹改了 code_sha256，R2-FINE 的 --resume 永久失效。

## 限制
- 單一 seed、只有 12 個 epoch 的資料點；k=5 的 OLS 解析度很低。
- 同期參照只有一個 run（R2）。
- R2-FINE 沒跑完，細分類對主指標的效果沒有可報告的答案。

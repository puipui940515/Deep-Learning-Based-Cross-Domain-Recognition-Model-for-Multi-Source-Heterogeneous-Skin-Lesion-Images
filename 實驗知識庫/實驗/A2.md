## 目的
使用者指出「空間頭的異常分數看起來沒有明確聚焦點」。助理追查後懷疑問題不在模型，而在 A1 的讀出方式。腳本要回答三件事：
- A：三種讀出方式哪一種才是「模型看了哪裡」，各自有多平。
- B：能量落在邊界還是內部（「抓取像痕跡」假說的量化版）。
- C：BCN 孔徑：高分格是否與 `valid()==0` 的孔徑區重疊（孔徑假說的直接檢定）。

## 做法
- run：`R0S_fae6ff22_seed17` 與 `_seed42`（pilot），val_select。
- 三種讀出（四來源各 80 張，seed 17）：
  - 讀出 A：每格 8 類 softmax 取惡性（BCC/MEL/SCC）和（A1 用的）。
  - 讀出 B：LSE 貢獻權重 softmax(cell_logit_k / T)，即 d(image_logit)/d(cell_logit)。
  - 讀出 C：預測類別的逐格 logit，平移到非負。
- 量：正規化熵、單格最大佔比、邊界一圈格子的能量佔比（7×7 格中邊界格佔 49%）、BCN 孔徑區能量佔比。
- 用讀出 B 重算 A1 的定位指標（每來源 100 張，兩 seed），忠實度改為等面積前 20% vs 後 20%，門檻 0.15。
- 另做「只翻轉」的 IoU，與 Grad-CAM 篩選腳本同條件比較；並輸出目視對比圖。

## 結果
三種讀出（seed 17，每來源 80 張）：

| 來源 | 熵 A / B / C | 最大佔比 A / B / C | 邊界能量 A / B / C |
|---|---|---|---|
| BCN | 0.953 / 0.5851 / 0.95 | 0.0486 / 0.2982 / 0.0461 | 0.5406 / 0.1573 / 0.3384 |
| HAM | 0.9371 / 0.6782 / 0.9581 | 0.0616 / 0.2378 / 0.0421 | 0.6446 / 0.139 / 0.3436 |
| ISIC | 0.9477 / 0.613 / 0.9563 | 0.0556 / 0.3103 / 0.0451 | 0.5925 / 0.199 / 0.3612 |
| PAD | 0.9474 / 0.5092 / 0.9419 | 0.0478 / 0.367 / 0.0516 | 0.5738 / 0.035 / 0.3079 |

BCN 有孔徑的影像：孔徑佔 18.58% 格數；讀出 A 在孔徑放 17.46% 能量，讀出 B 只放 3.77%。

讀出 B 重算定位指標：

|---|---|---|---|---|---|---|
| BCN | 0.4002 | 0.3638 | 0.1841 | 0.2473 | 0.5777 | 0.5392 |
| HAM | 0.3663 | 0.3267 | 0.2142 | 0.1574 | 0.6692 | 0.5225 |

只翻轉的一致性（執行紀錄）：HAM 0.476、BCN 0.550、ISIC 0.522、PAD 0.595；Grad-CAM 參考帶 0.44–0.65（24 個模型，最佳 0.647）。

## 推論
當時的結論（2026-10-26 12:00 後）：
- 撤回一：「異常分數指向標尺與孔徑」不成立。讀出 A 在孔徑是等比例、沒有偏好；讀出 B 主動避開孔徑。
- 撤回二：「圖是平的」只對讀出 A 成立。正確讀出下，49 格裡單一格扛 24–37% 權重，能量集中在內部。
- 忠實度從「HAM/ISIC 為負」變成 8 個（來源×seed）格子中 7 個過 0.15 門檻（ISIC seed 42 為 0.1316 未過）。
- 一致性與 Grad-CAM 相當，不是更好也不是更差；A1 拿八視角（含 90 度旋轉）去比 Grad-CAM 的只翻轉是不對等比較。
- 目視：ISIC 底部標尺不再被標亮，孔徑是暗的，亮點落在病灶上；BCN 一張 NV 亮點偏離病灶、HAM 一張 MEL 散成多點，這兩張不理想。
- 修正後結論：空間頭確實產生有聚焦、通過忠實度門檻、集中在影像內部的區域圖，且在選模準則上沒有分類代價；昨晚「定位不成立」是錯的。

後來：
- Day5（2026-11-09）助理曾引用 A2 說「spatial head 沒有贏過 gap」；同日稍後更正：A2 量的是讀出集中度，不是分數，不能支持這個說法。依 run 索引，`R0S-P_7816aed0_seed42`（224、空間頭、舊 manifest）得 0.6709，分數上沒有被比下去，需在同一個 manifest 上重看才算數（事件記憶中舊節點已標為被取代）。
- Day5 另一段引用 A2：邊緣格佔 49%，LSE 只放 BCN 15.7%／HAM 13.9%／ISIC 19.9%／PAD 3.5% 的權重，「只看病灶、不看背景」的功能存在，但沒有換成分數。

## 限制
- 無真值遮罩，只量一致性與忠實度，不是定位正確性；皮膚鏡來源的中央偏誤指標會虛高。
- 單一 run 的兩個 seed，pilot；讀出比較只用 seed 17、每來源 80 張。
- 只翻轉 IoU 的數字只在執行紀錄中，沒有獨立 JSON，紀錄也未寫明是哪個 seed。

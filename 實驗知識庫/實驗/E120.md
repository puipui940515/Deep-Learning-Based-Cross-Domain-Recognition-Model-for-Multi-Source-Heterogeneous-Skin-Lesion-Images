# E120　排除 ISIC 2018 Task 3 測試集的 manifest（為了人機對比）

<!-- 洩漏提醒 -->
> ⚠ **資料表提醒（2026-11-19 加註）**：本頁的數字量在 2026-11-18 之前的 manifest 上，那些 manifest 都有跨來源同病灶的切分洩漏（見 [HC2](HC2.md)）。同一份 manifest 內的相對比較仍可參考；絕對數字不要和 HC v2 的結果並列，洩漏對分數的影響尚未量化。

- 日期：2026-11-12
- 狀態：被 E123 取代（用此 manifest 的 R2-REG-LONG-H18 只跑到 epoch 1 就停止，改用排除所有 ISIC 挑戰賽測試集的 E123 manifest）
- 相關：前置 E112（重疊檢查）；配套 E121（manifest 覆寫等價性驗證與 split gate）；後續 E123、E124、E125

## 目的
使用者想做人機對比。查證結果：現行 manifest 沒有排除醫師判讀用的 ISIC 2018 Task 3 測試集——官方 1,512 張中 1,260 張（83.3%）在 manifest 裡，全部來自 ISIC_Archive_Expanded（train 956、val_select 158、val_assess 146）；train 內的 956 張依官方類別為 NV 702、MEL 125、BCC 70、AKIEC 34、DF 25。模型看過題目就不能和醫師比。使用者回覆「建立排除版」。

## 做法
- 不覆寫現行 `cp005_manifest.csv`，另寫 `data/cp005_manifest_holdout_isic2018.csv`。
- 排除三種列（標 split=excluded、training_eligible=False）：官方測試影像本身；與測試影像同 lesion_id 的其他照片（同一病灶換角度拍，等於看過題目）；E100b 雙門檻驗證過的近似重複。
- 另寫測試清單（1,512 張，含官方標籤、我們的標籤、原 split、是否在磁碟）供之後評估。
- 驗證（任一不過就不寫檔）：列數／欄位／順序相同；只有被排除的列變動且只變三個欄位；三個 split 內不再有測試影像、同病灶或近似重複；沒有 split_group_id 橫跨兩個 split；寫出後讀回一致。

## 結果
- 排除 1,462 列，全部在 ISIC_Archive_Expanded：測試影像 1,260、同 lesion_id 的其他照片 202（E100b 的近似重複 1 列已包含在同病灶內）。原本所屬 split：train 1,112、val_select 182、val_assess 168。

| split | 排除前 | 排除後 |
|---|---|---|
| train | 64,776 | 63,664 |
| val_select | 12,102 | 11,920 |
| val_assess | 9,588 | 9,420 |
| excluded | 68 | 1,530 |

- 沒有任何（來源, split, 類別）跨過 ≥30 門檻，選模指標的分母不變。
- 官方 252 張（全部 BKL 217 與 VASC 35）不在磁碟上。
- 官方 vs 我們的標籤：AKIEC→AKIEC 19、AKIEC→SCC 24、BCC 93、DF 44、MEL 171、NV 909 一致。24 張官方標 AKIEC 的影像在我們的 manifest 標成 SCC（2018 的七類沒有 SCC，侵襲性 SCC 被歸進 AKIEC，是詞彙差異不是標錯）。
- 驗證全過；現行 manifest 的 sha256 前後都是 29d29514…，未動。

## 推論
- 成績不能與現行 manifest 的 run 直接比；採用需要新的 split gate（現行 gate 綁 manifest_sha256）。
- 建立當下尚未訓練：train.py 的 manifest 路徑是全域設定，要用排除版需加 opt-in 覆寫（會改 code_sha256），在 seed 42 跑完前不動程式。
- 後續：seed 42 隨即依使用者指示停止（epoch 26，無 result.json）；E121 加入逐 run manifest 覆寫並驗證既有 90 組 cfg 不變，啟動 R2-REG-LONG-H18。同日稍後使用者決定「也要排除 ISIC 其他人使用的測試集」，E123 改為排除 9 個 ISIC 挑戰賽 collection（12,147 列），H18 在 epoch 1 停止、不算結果，改跑 R2-REG-LONG-HC。之後所有訓練用 E123 的 manifest，對照基準為 R2-REG-LONG-HC。
- 這也推翻了 E112 當時「人機對照這條路實際上不可行」的判斷（E124 實際完成對照）。

## 限制
- 只排除 ISIC 2018 Task 3 測試集，沒有排除其他屆挑戰賽測試集（這正是被 E123 取代的原因）。
- 後來 E125 發現補下載的 252 張中有 24 張的 lesion_id 出現在 HC manifest 的 train/val（E120 無法檢查不在磁碟上的影像）。

# E84　錯的圖片有沒有「特異性」：集中度、屬性富集、可預測性三層檢定

- 日期：2026-11-07
- 狀態：完成（第一、三層成立；第二層的富集被 E84b 證明大多是類別與來源的影子）
- 相關：前置 E80；後續 E84b（混淆檢查）、E84c（圖）、E85（特異性來源）、E86（影像特徵）、E88（盲點）

## 目的
使用者問「錯誤的圖片是否具有特異性」：模型錯的圖是一批可辨識的圖，還是隨機散落？

## 做法
- 分母 val_assess 9,652 張；七個模型：六個 ConvNeXt 系（R0-BAL s17／s42、R0 s17／s42、R1、R2）＋ swin_t（R2-SWIN）。只讀既有 logits 與 manifest，不重新推論。
- 第一層　集中度：同時答錯的模型數分布，對上「錯誤互相獨立」的虛無（2000 次虛無抽樣）。
- 第二層　屬性富集：七個全錯 vs 其餘，在 manifest 欄位上比分布；置換 5000 次、Holm 校正。排除 fitzpatrick_skin_type（95.5% 空）與 duplicate_status（只有一個值）。
- 第三層　可預測性：只用表格欄位預測「會不會被七個全錯」，LogisticRegression、5 折 StratifiedGroupKFold（依 patient_id 分組），AUC；以模型自身平均信心作參考。

| 1 | 778 | 8.06% | 3590.2 | 0.2 |
| 2 | 487 | 5.05% | 2601.3 | 0.2 |

2000 次虛無抽樣中七個全錯的最大值只有 2 張。

第二層：40 個 level 中 Holm 校正後 30 個顯著。未分層最強的幾個：label AKIEC 3.18×、SCC 3.24×、DF 3.21×、BKL 2.59×、MEL 1.71×、NV 0.38×；mapping_relation=family 2.41×、mapping_confidence=medium 2.66×；recommended_sample_weight=0.8 → 0.00×（651 張無一進全錯集）；diagnosis_confirmation_confidence=medium 0.04×；source BCN20000 1.78×；site head_neck 1.82×；年齡 全錯 62.0 歲 vs 其餘 50.3 歲。

第三層：

| 預測子 | AUC（平均 ± 標準差） |
|---|---|
| 只用 label_name | 0.7422 ± 0.0222 |
| metadata（不含 label，含年齡） | 0.7812 ± 0.0174 |
| metadata + label | 0.7988 ± 0.0205 |
| 模型自己的平均信心（參考） | 0.7374 ± 0.0164 |
| 信心 + metadata + label | 0.8111 ± 0.0166 |

七個全錯的天花板：六個 ConvNeXt 0.9213 → 加 swin 後 0.9276（+0.63pp）。

## 推論
- 錯誤是結構性的，不是雜訊：U 形分布（兩端高、中間低）；加入不同家族（swin）沒有改變這個形狀。
- 完全不看圖、只用表格欄位就有 0.78–0.80 的 AUC，比模型自己的信心（0.737）還高。
- 第二層有兩個反直覺結果（標籤可靠度被調低的圖反而幾乎不會被全錯），觸發 E84b；E84b 顯示這些富集幾乎全是 (類別, 來源) 的影子，第三層的 0.78 也幾乎全部來自 label + source（基準就 0.7627）。
- 後來 E88 指出方法上的盲點：E84 到 E86 都以「七個全錯集合」為對象，而 val_assess 內 64 張純白影像因為有一個模型剛好猜中 BCC，從定義上就在分析範圍外。

## 限制
- 第三層的 AUC 是可預測性，不是因果；metadata 預測得到不代表 metadata 造成錯誤，它們共同反映「哪些病灶本來就難分」。
- 全部單種子 seed 17；比例是 val_assess 的全量普查。
- 699 張不是 699 個獨立難例（E85 乙：約 480 個 group）。

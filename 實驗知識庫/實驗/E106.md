# E106　最佳模型的混淆矩陣（合併＋分來源，val_assess）

- 日期：2026-11-09
- 狀態：完成
- 相關：模型同 E110；同資料換樣式重畫為 E113；E109 與 E112 引用其判讀；E117 缺陷 C1 出自此處

## 目的
使用者要看最佳模型的混淆矩陣。因為選模指標是 worst-source，而 ISIC 佔 val_assess 的 72%（6,911／9,588），合併矩陣會被 ISIC 主導、看不出 BCN 壞在哪裡，所以必須分來源畫。

## 做法
- 模型：R2-REG-LONG_45fb4e79_seed17，ep51；資料：val_assess，n=9,588；只讀既有 `val_assess_logits.npz`，不跑模型、不碰 GPU。封存測試集未使用。
- 五個面板：四來源合併、每來源各一張、最大錯誤去向排行。每格顯示「張數／該列百分比」（列百分比＝recall）。
- 該來源 support < 30 的類別不計入 macro_f1_ge30，圖上以灰字標示。

## 結果

整體：accuracy 0.8317、balanced accuracy 0.6736。

| 來源 | n | accuracy | macro_f1_ge30 |
|---|---|---|---|
| BCN20000 | 1,462 | 0.7421 | 0.6819（最差） |
| HAM10000 | 994 | 0.8913 | 0.8313 |
| ISIC_Archive_Expanded | 6,911 | 0.8416 | 0.6963 |
| PAD-UFES-20 | 221 | 0.8462 | 0.8636 |

合併的逐類 recall：AKIEC 0.5263、BCC 0.8858、BKL 0.6688、DF 0.5174、NV 0.9234、VASC 0.7111、MEL 0.7049、SCC 0.4513。

對角線最差的幾格：

| 格 | recall | 主要去向 |
|---|---|---|
| BCN AKIEC | 40/102 = 39% | BCC 27%、BKL 14%、MEL 13% |
| ISIC SCC | 102/226 = 45% | BCC 20%、AKIEC 16%、BKL 14% |
| ISIC AKIEC | 101/210 = 48% | BKL 14%、BCC 13%、MEL 13% |
| BCN BKL | 75/123 = 61% | — |
| BCN MEL | 252/384 = 66% | NV 23.4%（90 張） |
| HAM DF／BCN DF | 5/15 = 33%／1/13 = 8% | support < 30，不計入指標 |

最大單一錯誤去向（張數，佔該真實類別 %）：ISIC NV→MEL 197（4.8%）、ISIC MEL→NV 118（17.3%）、BCN MEL→NV 90（23.4%）、ISIC BKL→MEL 54（10.6%）、ISIC NV→BKL 49（1.2%）、ISIC SCC→BCC 45（19.9%）、BCN NV→MEL 45（8.7%）。

## 推論
1. MEL ↔ NV 是雙向的主要混淆。臨床上嚴重的是 MEL→NV：BCN 23.4%、ISIC 17.3%，BCN 每四顆黑色素瘤就有將近一顆被判成良性痣。
2. 角質細胞那一群（AKIEC／BCC／BKL／SCC）彼此糾纏；與先前查到的「SCC in situ 全部對映到 AKIEC」是同一條線上的問題，這四類在組織學上本來就連續。
3. NV 在各來源都強（HAM 95%、ISIC 93%、BCN 84%），它是最大類，所以合併 accuracy 0.8317 幾乎是 NV 撐起來的；**不可以報 accuracy**。
4. PAD 的 0.8636 只建立在 3 個類別上（DF／VASC／SCC 為 0 張，MEL 只有 2 張）。
- 後續：E112 指出 AKIEC 0.5263 與文獻中人類專家的 51.2% 幾乎重合；E117 把「BCN 黑色素瘤 23.4% 被判成痣」列為缺陷 C1。

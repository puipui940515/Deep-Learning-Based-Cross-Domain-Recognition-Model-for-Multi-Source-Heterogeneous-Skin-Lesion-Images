# E64　表面起伏線索分不分得出「隆起型」與「平坦型」病灶

## 目的
E63 用八類最差來源評 C 類，等於用一把不量這件事的尺。這支直接檢定 C 類自己宣稱的物理假說：起伏線索能不能分出臨床上常呈**隆起**（BCC 結節型、DF、VASC）與常呈**平坦**（AKIEC、BKL、NV）的病灶？只有 C 的 AUC 明顯帶來 RGB 沒有的東西，才代表起伏線索有新資訊。同時逐來源報，看 C 是否只在某些拍法有效。

## 做法
- 二分類：隆起 BCC/DF/VASC vs 平坦 AKIEC/BKL/NV；MEL 與 SCC 兼有扁平與結節型、標籤不乾淨，不收。
- 三組特徵：只用 C（13 維）、只用 RGB 統計量（42 維）、RGB＋C；指標 AUC。
- train 擬合（5,666 張）、val_select 評分（10,436 張）；val_assess 讀 0 次。

## 結果
| 特徵集 | 整體 AUC | BCN20000 | HAM10000 | ISIC | PAD-UFES-20 |
|---|---|---|---|---|---|
| 只用 C（13 維） | 0.6569 | 0.5805 | 0.5789 | 0.6966 | 0.5497 |
| 只用 RGB（42 維） | 0.8373 | 0.8061 | 0.8875 | 0.8531 | 0.6140 |
| RGB ＋ C | 0.8383 | 0.7923 | 0.8734 | 0.8571 | 0.6356 |

RGB＋C 對 RGB 的整體增量 +0.0010；C 對 RGB −0.1804。

## 推論
- 只用 C 的 AUC 0.6569 明顯優於亂猜，**起伏線索是真的、量得到**。
- 但加到 RGB 上只有 +0.0010，**幾乎完全與顏色冗餘**。
- 逐來源 RGB＋C 對 RGB 的增量**只有 PAD 是正的**（0.6140 → 0.6356）；PAD 是手持手機臨床照、有真實景深的來源，方向上說得通。
- 後來 E65 用 MiDaS 真深度做同一任務：PAD 同樣是唯一有意義的增量（+0.0671），兩套獨立方法同向。E65 也指出手工線索單獨 AUC（0.6569）高於真深度（0.5918），但那代表手工線索其實在撿顏色與亮度的相關性，不是在量幾何。

## 限制
- C 是全域統計量，量不到空間結構（局部高光與陰影），CNN 吃得到的它吃不到；這裡只檢定物理假說的方向。
- 「隆起／平坦」是以類別代替的粗略標記，不是逐張的形態標註。
- 單一 seed。

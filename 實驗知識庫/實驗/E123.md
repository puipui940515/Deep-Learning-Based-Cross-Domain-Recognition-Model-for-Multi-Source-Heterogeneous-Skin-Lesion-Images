## 目的
E120 只排除了醫師判讀用的 ISIC 2018 Task 3 測試集。使用者要求「醫師測試集」與「ISIC 其他人所使用的測試集」都要排除，包含當前訓練，這樣之後才能和醫師及其他研究的成績比較。

## 做法
- 測試集清單：ISIC Archive 官方 API 的 collection 搜尋（只讀 metadata、未下載影像），9 個 collection 逐一核對張數與 API count 一致。
- 不覆寫現行 `cp005_manifest.csv`，另寫 `cp005_manifest_holdout_isic_challenges.csv`。被排除的列設為 excluded，原因依優先序只標第一個：官方 Test → 官方 Validation → 與上述同 lesion_id → E100b 驗證過的近似重複。
- 官方 Validation collection（2017、2018 Task 1-2、2018 Task 3）是助理自己保守加的（使用者只說測試集），原因碼獨立，可單獨放回；使用者 2026-11-12 17:09 回覆「維持排除」。
- 驗證 a–e：列數／欄位／列順序與母 manifest 相同；只有被排除的列變動且只變三個欄位；三個 split 內無官方測試／驗證影像、同病灶、近似重複；無 split_group_id 跨 split；train 仍有八類。任一不過就不寫檔。另產生 split gate（腳本關卡）。
- config.json 登記 R2-REG-LONG-HC（= R2-REG-LONG + manifest 覆寫），停止 H18（epoch 1），05:19:53 啟動 R2-REG-LONG-HC_414cd7b2_seed17，訓練設定與 seed17 最佳模型逐鍵相同。

## 推論
- 之後所有訓練一律用這份 manifest，對照基準是 R2-REG-LONG-HC。
- 舊 manifest 上的成績（0.6819／0.6728）不能和新 manifest 的成績直接比；HC 的 0.6823 與舊 manifest 的 0.6819 也不可直接比。
- 後來 E125 發現補下載的 252 張 2018 Task 3 測試影像中有 24 張與此 manifest 的 train/val 同病灶（這些影像原本不在 manifest，所以本次的同病灶排除沒涵蓋到），留待下一代 manifest 處理。

## 限制
- 原因只標第一個，各原因計數不是互斥的全部歸屬。
- 近似重複只用 E100b 驗證過的配對；未對官方影像做新的全面重複掃描。
- 只處理 ISIC 挑戰賽 collection；其他研究若用自訂切分，不在本次範圍。

## 目的
E25 的逐類自由偏置有八個自由度，E26 的目標各有取捨。E26b 問一個最簡單、最不容易過擬合的版本：只對三個弱類別（AKIEC、DF、SCC）加同一個偏置，偏置值在 val_select 上選，能在 val_assess 上拿回多少、代價是什麼。

## 做法
- 基準 R2（`R2_0edf1ecc_seed17`），只讀既有 logits。
- 在 val_select 上掃偏置 0 到 2.5（間隔 0.25），分別依「選定指標」與「macro recall」各挑一個值。
- 把挑出的兩個偏置套到 val_assess，報逐類 recall（含 Wilson 95% 區間）、precision、F1。
- 由一段 inline 腳本產生，沒有獨立的 audit 腳本。

## 結果
val_select 上的選擇：依選定指標挑到 +0.50（val_select 0.6889），依 macro recall 挑到 +1.00。

val_assess（數字取自 E24 合併報告）：

| | 不調整 | +0.50（選定指標最佳） | +1.00（macro recall 最佳） |
|---|---|---|---|
| 選定指標 | 0.6541 | 0.6621（+0.80pp） | 0.6626（+0.85pp） |
| macro recall | 0.6903 | 0.6992（+0.89pp） | 0.7021（+1.18pp） |
| AKIEC recall／F1 | 0.509／0.538 | 0.526／0.543 | 0.556／0.542 |
| DF recall／F1 | 0.599／0.682 | 0.634／0.699 | 0.645／0.698 |
| SCC recall／F1 | 0.562／0.519 | 0.611／0.529 | 0.619／0.508 |
| NV recall | 0.906 | 0.905 | 0.903 |
| MEL recall | 0.717 | 0.711 | 0.705 |

Wilson 區間（不調整 → +0.50）：AKIEC [0.460, 0.558] → [0.477, 0.575]；DF [0.524, 0.669] → [0.560, 0.702]；SCC [0.497, 0.625] → [0.546, 0.672]，三類全部重疊。

precision 變化：DF 0.792 → 0.779（+0.50）；SCC 0.483 → 0.466（+0.50）→ 0.431（+1.00）。

## 推論
- DF 的 F1 真的上去（0.682 → 0.699），precision 幾乎沒掉 → 真實收益。
- AKIEC 的 F1 幾乎不動（0.538 → 0.543 → 0.542）：recall 買得到，precision 同額付掉。
- SCC 在 +1.00 時 F1 掉到 0.508，比不調整還低 → 推得越用力越糟。
- 三類的結果，E24 第 1 節的 recall／precision 組合事前就全部預測對了。
- +0.50 是一個「方向對、幅度小、而且免費」的改善，不是戰果：三類 Wilson 區間全部重疊，選定指標的 +0.80pp 也在種子噪音帶（1.68–3.69pp）之內。

## 限制
- 單一模型 R2、單一種子；val_select 只有一份。
- 沒有一項達到統計顯著。
- 偏置會改變模型校準，依賴信心值的下游要重新校準。

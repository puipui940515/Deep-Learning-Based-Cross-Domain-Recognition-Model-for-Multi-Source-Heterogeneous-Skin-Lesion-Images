# E16　各版本訓練曲線疊圖：發現每個 run 都是被 epoch 預算截斷

- 日期：2026-11-02（04:40 首版；09:20 R2-REG 跑完後重畫）
- 狀態：完成；其發現更正了 E12 第 1–3 節
- 相關：更正 E12；E18 第 6 節重畫並更新；E21 A8；E22 清冊的「預算截斷」欄；後續 E43；ADR 0001

## 目的

把所有 run 的訓練曲線畫在同一張圖上比較。這些 run 橫跨好幾週，`metrics.py` 演進過，早期 run（R0、R0-BAL、R0-AUG）的 result.json 沒有 ge30 欄位，直接讀會是三種定義疊在一起。

## 做法

- `audit/e16_curves.py`：每個 epoch 的混淆矩陣都存在 history 裡，一律從混淆矩陣重算 macro_f1_ge30（只平均支撐數 ≥ 30 的類別），定義與現行 `metrics.py` 一致。
- 三個 panel：worst-source、mean-source、train loss。
- train loss 標註不可跨 run 比高低：mixup／cutmix 強度不同會改變交叉熵的數值尺度（R0-AUG、R2-REG），只能看各自的下降形狀。
- 04:40 首版時 R2-REG 還在跑，讀 progress.json 畫虛線；09:20 跑完後重畫。

## 結果

各 run 的最佳點與末值（val_select worst-source macro F1 ge30，取自 E18 第 6 節的重畫結果）：

| run | 最佳 | 末值 | 跑了 |
|---|---|---|---|
| R0 tiny@224 e0.5 | 0.6667 @ep12 | 0.6667 | 12 |
| R0-BAL tiny@224 e1.0 | 0.6606 @ep12 | 0.6606 | 12 |
| R0-AUG tiny@224 重增廣 | 0.5913 @ep5 | 0.5707 | 8（早停） |
| R1 tiny@320 | 0.6694 @ep17 | 0.6694 | 17 |
| R2 small@384 | 0.6845 @ep20 | 0.6845 | 20 |
| R2-REG small@384 + 正則 | 0.6907 @ep17 | 0.6853 | 20 |

唯一的共同預算第 12 epoch（sample_exponent 固定 1.0）：

| run | 第 12 epoch |
|---|---|
| R0-BAL tiny@224 | 0.6606 |
| R1 tiny@320 | 0.6561 |
| R2 small@384 | 0.6594 |

R2 到第 13 epoch 才拉開（0.6804）。R0-BAL 在現行指標下 ep8 0.6500 → ep12 0.6606 仍在爬；R0 ep10 0.6665 → ep12 0.6667。

## 推論

- 除了 R2-REG（首版時尚未跑完），每個 run 的最佳 epoch 都是它的最後一個 epoch——它們是被預算切斷，不是收斂。E12 原本說「R0-BAL best=8、後 4 個 epoch 沒進步、大致收斂」是用舊的 `worst_source_balanced_accuracy` 判的。
- E12 的卷積成本階梯同時在爬「卷積成本」與「12／17／20 epoch 預算」兩軸，無法分離；在共同預算上三者差不到 0.5pp。也不能反過來說卷積成本沒用（大模型需要更多 epoch 是正常的，且 R2 一個 epoch 18.5 分鐘、R0 9.8 分鐘）。
- 建議 R0-BAL 以現行設定（20 epochs、patience 6、ge30 選定、seed 17）重跑以固定預算軸，約 3.3 小時。
- R0-AUG 是圖上唯一明顯往下走的，但只跑 8 個 epoch 又是舊規則早停，不能據此判定重增廣有害。
- 重畫後：R2-REG 是第一個「最佳 epoch 不是最後一個」的 run（ep17 轉頭）。但 `CosineAnnealingLR` 的 T_max 等於 epochs，這只是「20 epoch 這條餘弦曲線的頂點」，不能外推到 55 epoch 的 R2-LONG。

後來 E43（2026-11-04）用末 3 epoch 斜率重查，結論為「預算截斷是真的，但只有 R1 真的被害到」（R1 +0.510pp/ep）；同日 R1 以 20 epoch 重跑，best_epoch 仍是 20/20，val_assess 0.6664，與舊檢查點的差距都落在種子噪音帶內。

## 限制

- 只有圖與報告內表格，沒有獨立的 json 或 md 報告；數字散見於 E12 追記與 E18 第 6 節。
- 「預算截斷」只看最佳 epoch 是否為最後一個，被早停攔下的 run 會標「否」，那是另一回事。
- 全部單一 seed（17）。

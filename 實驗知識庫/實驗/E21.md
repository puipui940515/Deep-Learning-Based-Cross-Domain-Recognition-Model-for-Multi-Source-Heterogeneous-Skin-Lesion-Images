## 目的

把 E5、E10–E20 的結論收攏成一份，給出「已確立的問題」「已排除的解釋」「未完成事項」與問題排序。基準模型是 R2（convnext_small@384），val_assess 準確率 0.8173、worst-source macro F1(ge30) 0.6541。

## 做法

不做新計算，數字回核各 JSON。分為：A 已確立、B 已排除、C 未完成／未核准、D 問題排序、E 本身的限制；2026-11-04 加 F 節修正，原文保留不動。

## 結果

已確立的問題（A）：

| 編號 | 內容 | 關鍵數字 |
|---|---|---|
| A1 | 錯誤是系統性的（E17） | 七模型全錯 718／9,652（7.44%），虛無預期 0.1 張；R2 錯誤 43.1% 共錯、15.9% 像變異；天花板 0.9213，空間 10.39pp |
| A2 | 正則化沒用且削必要記憶（E18） | +1.30pp，bootstrap −0.76～+3.37pp 含 0；760 張只修 42 張；淨 −42；落差縮 2.92pp 中 78% 來自訓練下降 |
| A3 | MEL↔NV 是真實視覺重疊（E17） | MEL→NV 96、NV→MEL 83，雙向 179 張佔共錯 23.6% |
| A4 | SCC 被取樣器卡住（E20） | SCC 1,687 張抽 3.12%；DF 489、VASC 377 各抽 10.27% |
| A5 | BKL 桶異質（E19） | 同來源 Solar lentigo 35.90%、LPLK 35.59% vs SEK 12.03% |
| A6 | 影像模糊佔一小塊（E19） | lap_var<15：25.00% vs 11.25%，約 99 張佔共錯 14% |
| A7 | 有放回抽樣看不完（E20） | 單 epoch 31.8%；20 epoch 後仍有 7,739 張（11.9%）沒被抽到 |
| A8 | 幾乎每個 run 都被預算截斷（E12 追記、E16） | 共同預算 ep12：0.6606／0.6561／0.6594，差不到 0.5pp |
| A9 | 沒有同結構重複種子 | R1、R2、R2-REG 只有 seed 17；噪音基線只能借 tiny@224 的 1.68–3.69pp |

已排除（B）：資料洩漏（`cp005_group` 橫跨 0 張）、重複影像（`duplicate_status` 全為 unique）、標籤太弱、family／exact 旗標（作廢）、AKIEC 的 SCC in situ（無證據）、墨跡／來源指紋、解析度、棄權、病灶面積 confound（A1 作廢）。其中 family 桶與 SCC in situ 兩條是助理自己先前推薦、後被自己數據推翻的。

問題排序（D）：系統性錯誤約 43%、中間地帶約 41%、變異／過擬合約 16%。能動第 1 項的可量化線索只剩 SCC 取樣上限、BKL 桶異質、影像模糊三條，加起來能動多少沒量過。

未完成（C，截至撰寫時）：R0-BAL 20 epoch 重跑、R2-LONG、形態學墨跡偵測器、718 張醫師判讀、mask<2% 的 9.5% 影像、Fitzpatrick17k 與 DDI；封存測試集從未使用。G-DET 閘門一列於 2026-11-04 更新為「由使用者在知情後核准（兩欄皆 true），附帶影響必須是單向的條件」。

F 節修正（2026-11-04）：

| | 答對 | 共錯 | 只有自己錯 | 答對 − 共錯 |
|---|---|---|---|---|
| R2 自己的最高分 | 0.8564 | 0.7680 | 0.6906 | 0.093 |
| 九個等權平均的最高分 | 0.7703 | 0.6038 | 0.4610 | 0.167 |

- 依集成最高分棄答，40% 覆蓋率下共錯留存 7.6%、非共錯留存 42.8%；但集成在 760 張上只修對 1 張。
- 九個等權平均 val_assess 準確率 0.8332（距天花板 8.81pp）；選定指標 0.6541 → 0.6890（+3.49pp，CI [+1.12, +5.66] 不含 0）。
- SCC 只存在於一個來源，拉高取樣不會產生跨來源訊號，R2-SCC 不建議重跑；逐欄排名／百分位組合會崩（e36 排名平均 0.5595，e37 兩個 arm 約 0.43）。

## 推論

- 一句話：主要問題不是過擬合，是系統性錯誤；模型端所有介入加起來上限 10.39pp，已被 R2-REG 直接驗證。
- 後來 F 節修正：「棄權救不了」只對 R2 自己的信心成立，對集成信心不成立；「修」與「避」不是同一件事。上限本身不變，但集成已吃掉其中 1.59pp（15.3%），是 2026-11-02 之後第一個區間不含 0 的模型端進步（ADR 0007）。
- 後來 E100（2026-11-09）找到 1,682 對重新編碼的重複影像、148 張 val_assess 影像在 train 有雙胞胎，B 節「資料洩漏、重複影像已排除」依 manifest 旗標的判斷不成立。
- 後來 E80（2026-11-07）以 swin_t 檢驗，43% 共錯率不是 ConvNeXt 的產物，E 節第一條限制的那個缺口補上。

## 限制

- 七模型全是 ConvNeXt；「共錯」依賴這七個模型；沒有醫師判讀。
- lap_var 是模糊代理；A4、A7 是期望值；A5 的 BKL 次類樣本小（78、59）。

## 前因與後果

**前因**
- 支持｜[E12](E12.md)（加卷積成本（更大骨幹、更高解析度）有沒有用？要不要加一條）：E12 的修正附錄提供共同預算數字，支持 E21 的截斷判斷。
- 支持｜[E13](E13.md)（「先隔離再入場」做得到嗎？用 (B−R) 顏色判據逐張找）：E13 尚未實作形態學判據，支持 E21 將此列為未完成事項。
- 支持｜[E16](E16.md)（各版本訓練曲線疊圖：發現每個 run 都是被 epoch）：E16 的逐 epoch 重算支持 E21 A8 的預算截斷判斷。
- 支持｜[E17](E17.md)（現在的問題真的是過擬合嗎？用多模型錯誤重疊來分辨）：E17 的共錯與混淆結果支撐 E21 A1、A3 的問題總結。
- 支持｜[E17c](E17c.md)（val_assess 上的六模型共錯集（E17 主結論的）：E17c 的共錯拆解與天花板數字支撐 E21 的系統性錯誤總結。
- 支持｜[E18](E18.md)（R2-REG：加強正則化（mixup 0.8 + ran）：E18 的區間與召回變化支撐 E21 A2 對正則化效果的總結。
- 支持｜[E19](E19.md)（那批共錯，是不是驗證集自己的問題？）：E19 的次類與品質分析提供證據，因此支撐 E21 的 BKL 異質與模糊判斷。
- 支持｜[E19c](E19c.md)（E19 第三部分：把貼紙上的印象量化（模糊、解析度、藍色）：E19c 的模糊比例差異提供量化證據，因此支撐 E21 的 A6 判斷。
- 支持｜[E20](E20.md)（現在訓練實際使用的資料分布（檔案裡有什麼 vs. 取樣器）：E20 算出 SCC 抽取佔比與覆蓋率，因此支撐 E21 的 A4、A7 判斷。
- 支持｜[E80](E80.md)（事先登記：swin_t 的錯誤與「六個 ConvNeXt）：E80 換用 Swin 仍看到共錯現象，因此支持 E21 的系統性錯誤判斷。
- 推翻或更正｜[E100](E100.md)（同一張圖掛到不同標籤？以影像內容獨立檢查重複影像）：E100 找到跨切分真重複，因此推翻 E21 已排除洩漏與重複的判斷。
- 推翻或更正｜[E36](E36.md)（2026-11-04 自主時段：事先登記與免訓練集成家族）：E36 的集成取得顯著進步，因此更正 E21 尚未兌現模型端空間的盤點。
- 推翻或更正｜[E38](E38.md)（「棄權救不了」與「棄答很有用」是不是矛盾（事後探索））：E38 區分集成信心與單模型信心，因此將 E21 棄權救不了的說法加上條件。

**後果**
- 支持｜[ADR-0004](ADR-0004.md)（主要問題不是過擬合，而是多個模型錯在同一批影像上的系統性）：E21 彙整共錯與正則化證據，支持 ADR-0004 的主因判斷。
- 支持｜[ADR-0005](ADR-0005.md)（「七個模型為什麼錯在同一批影像上」已被排除的解釋清單）：E21 彙整已排除的解釋，為 ADR-0005 清單提供整理依據。
- 支持｜[ADR-0006](ADR-0006.md)（排除大部分解釋後，僅存的幾條有數字支撐的線索（SCC 取）：E21 整理三條可量化線索，支持 ADR-0006 的研究方向排序。
- 支持｜[E23](E23.md)（class_floor：給 SCC 一道類別抽樣質量保底）：E21 盤點 R2 缺少重複種子，因此支撐 E23 無同結構噪音基線的限制。
- 沿用｜[E32](E32.md)（共享骨幹階梯：完全共享 vs 部分共享 vs 完全不共享）：因噪音帶出處包含 E21，E32 沿用該數值制定判讀門檻。
- 沿用｜[E79](E79.md)（通用的訓練進度曲線與停滯判斷工具（套用於 R2-SWIN）：因為 E79 需要可主張改善的門檻，所以沿用 E21 彙整的種子噪音帶。

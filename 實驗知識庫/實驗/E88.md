## 目的
E87 看接觸圖時，肉眼發現「正常的 BCC」那一列有一張幾乎全白。本實驗要回答：整份資料裡有多少張這種退化影像、分布在哪些切分、為什麼沒被既有稽核抓到、對選模指標與逐類成績有多大影響；同時查證 E87 當下「模型學到純白 → BCC」的推測。

## 做法
- 掃描整份 manifest 86534 列，判準「48×48 縮圖的灰階標準差 < 0.012」（掃描在背景執行，讀取失敗 0 張）。
- 依切分、來源、標籤、分組（group）統計退化影像。
- 用七個既有模型在 val_assess 既有 logits 上的預測，逐模型查這批影像被預測成什麼。
- 影響評估：五個 run 在 val_assess 上「含／不含這批影像」的選定指標（worst_source_macro_f1_ge30）與 ISIC 的 BCC 逐類 F1。
- 不重新推論、不改 manifest、不刪任何檔案。

## 推論
- **更正 E87**：E87 說「模型學到純白 → BCC、會虛增 BCC 表現」是錯的。當時把快取中「不是七個全錯」讀成「模型答對」；逐模型查完，七個裡只有 R0-BAL s42 說 BCC，其餘說 MEL 或 NV。對 R2 家族而言，這批圖是**壓低** BCC 的 F1。模型之間不一致，代表「純白」落在決策邊界附近。
- 選定指標 worst_source_macro_f1_ge30 五個 run 都是 +0.00pp：val_assess 的最差來源是 BCN20000 不是 ISIC，這 64 張動不到地板；val_select 一張都沒有，所以所有選檢查點的決定完全沒受影響。受影響的是 ISIC 的 BCC 逐類 F1（R2 家族被壓低約 2.7–2.8pp；R1 因為猜 NV 而方向相反）以及 64 筆虛假的 MEL 偽陽性。
- 94% 落在 val_assess 不是巧合，是依病人分組切分的必然，切分邏輯沒有錯；去重沒抓到是「位元組雜湊」方法的盲點，不是執行錯誤。
- SWIN 對全白圖有 0.878 的信心說它是黑色素瘤，被記為一個值得單獨注意的校準問題。
- 方法論教訓：E84 到 E86 共四輪數值分析都以「七個模型全錯的集合」為對象，而這 64 張因為 R0-BAL s42 猜中 BCC 而不在集合內，從定義上就在分析範圍外；看接觸圖不到一分鐘就撞到。以錯誤集合為對象的分析有系統性盲點。
- 當時建議的處置方向（待人決定）：在 manifest 以 exclusion_reason 排除而非刪檔；去重改用像素內容雜湊；報告 BCC 逐類數字時標註這 64 張。使用者後來指示「先排除」，見 E90；像素內容層級的重複檢查見 E100。

## 限制
- 判準是縮圖灰階標準差，只抓得到純色圖，抓不到「有內容但錯誤」的圖（貼錯標籤、拍到別的部位）。
- 影響評估只看 val_assess 上的五個 run。
- 封存測試集未使用；本實驗沒有刪除、排除或修改 manifest。

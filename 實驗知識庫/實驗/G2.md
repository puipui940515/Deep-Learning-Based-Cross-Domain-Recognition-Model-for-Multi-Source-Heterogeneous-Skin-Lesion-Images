## 目的
G1 確認熱區很集中之後，使用者想知道熱區的型態還跟哪些因素有關。

## 做法
- **權重**：R2-HC-S20 seed 17 best.pt（HC manifest，修正前）。
- **樣本**：與 G1 同一批 val_select 隨機 200 張。
- **推測**：寫程式前先列出 9 個推測 H1–H9。
  - 這些推測是看過熱力圖之後才提出的，屬探索性。
  - 22 個置換檢定一起做 Holm 校正。
- **追查**：H7 的訊號集中在一小群影像，再從中隨機抽 8 張逐張目視。

## 結果
| 推測 | 結果 |
|---|---|
| H1 來源之間熱區型態不同 | 集中度中位數 BCN 0.773、HAM 0.685、ISIC 0.763、PAD 0.831。HAM 對其他來源未校正 p = 0.018，Holm 後不顯著 |
| H2 黑素類與角質類不同 | 角質類較集中（0.814 vs 0.731）、框內比例較高（0.919 vs 0.802）。未校正 p 0.013／0.033，Holm 後不顯著 |
| H3 答錯是否更依賴局部（控制信心） | 低信心三分位內，遮最熱後預測不變：答對 0.58（31 張）、答錯 0.28（25 張）。保持率與信心 ρ = 0.309 [0.117, 0.413] |
| H4 熱區被拉向畫面中心 | 病灶不在中央的只有 23 張，無法判斷（p 0.83） |
| H5 框內正貢獻偏邊緣或內部 | **偏內部**：環帶質量中位數 0.58，低於環帶面積 0.75。Holm 後 p = 0.0044，是唯一顯著的一項 |
| H6 四角（皮膚鏡暗角）吸走熱區 | 四角質量中位數 0.046，與暗角程度 ρ = 0.051 [−0.086, 0.184]，看不出關係 |
| H7 長寬比越偏離 1，框內比例越低 | ρ = −0.35；控制病灶面積後偏相關 −0.126。集中在 ISIC 長寬比約 1.5 的小病灶：26 張中 21 張框內比例 < 0.3，但答對率 0.88 |
| H8 亮度與集中度 | ρ = −0.009 [−0.145, 0.131]，無關 |
| H9 答錯時，預測類與真實類的熱區是否同一處 | 37 張答錯的 CAM 餘弦相似度中位數 0.168，≥ 0.5 的只有 2.7%：大多看不同的地方 |

**H7 的追查**：從那 21 張中隨機抽 8 張逐張看。
- 其中 7 張是 NV，熱區落在畫面邊緣的彩色圓形貼片上，不在病灶上。
- 這 7 張的確診方式都是「single image expert consensus」。
- HC manifest 中，ISIC 以這種方式確診的有 11,794 筆，其中 NV 佔 11,489 筆（97.4%）。
- ISIC 長寬比在 1.45–1.56 之間的 14,298 筆中，NV 佔 79.4%；其他長寬比為 55.8%。

## 推論
- **H5 是唯一經得起多重比較校正的結果**：模型主要看病灶內部，不是邊緣。
- **可能的捷徑**：
  - ISIC 有一個子群：長寬比約 1.5、畫面邊上貼著彩色貼片、以單張影像專家共識確診，幾乎全是 NV。
  - 模型在這群影像上答對率高，卻看著貼片。這符合「捷徑學習」：模型可能是靠拍攝條件，而不是病灶本身判斷 NV。
  - 這是 P030 附錄 A1「貼片子研究」的由來：遮掉貼片與遮掉等面積的非病灶皮膚，比較預測改變多少。
- H3、H9 顯示，答錯的影像更依賴單一局部，而且看的地方跟正確答案不同。

## 限制
- 全部是事後提出的探索性推測。除了 H5，都不能當結論引用。
- 貼片的盛行率沒有做隨機抽樣，不能主張「多少比例的 NV 有貼片」。
- 8 張目視只是線索，不是統計。
- 用的是修正前（HC）的權重。G1 顯示 HC v2 的熱區行為類似，但本頁沒有在 HC v2 上重跑。

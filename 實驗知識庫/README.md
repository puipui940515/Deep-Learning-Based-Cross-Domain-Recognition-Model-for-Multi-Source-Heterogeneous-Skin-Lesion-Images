# SkinDetect 實驗知識庫

這個資料夾收錄 CP-005 階段（2026-10 起）做過的每一個實驗與提案：為什麼做、怎麼做、得到什麼、結論是什麼、後來有沒有被推翻。
整理日期：2026-11-17。數字一律抄自原始報告與執行紀錄，沒有重新估算；原始報告、腳本與 run 結果在本機專案 `模型改進/` 底下，沒有隨本倉庫公開。

- [`實驗/`](實驗/)：每個實驗編號一頁，固定段落：目的／做法／結果／推論／限制／來源檔案。共 194 頁。
- [`提案/`](提案/README.md)：提案登記簿。每個想法先登記（誰提、何時、內容、階段），要做成實驗的在開跑前寫好判定門檻，事後不改門檻。共 23 案。

## 怎麼讀

**編號**
- `A0`–`D3`、`P0`、`R0`、`S0`：CP-005 初期的稽核與閘門（遮罩、空間頭、第九類、增強、來源探針、病灶框、資料盤點）。
- `E1`–`E144`：依時間編號的實驗。帶 `b`、`c` 的是同一實驗的補充或子步驟。
- `ADR-0001`–`ADR-0007`：已定案的設計決策（選模指標、取樣器、人工閘門等）。
- `P001`–：提案登記簿編號，與實驗編號互相引用（例如 P002 → E139）。

**狀態用語**：完成、不採用（依預先登記的規則判定沒有用）、作廢（實驗本身有錯或沒跑成）、被 Exx 取代／更正、進行中、擱置。

**讀數字前要知道的事**
1. **主指標**是 `worst_source_macro_f1_ge30`：每個資料來源各算 macro-F1（只計該來源張數 ≥30 的類別），取四個來源中最低的那個（[ADR-0001](實驗/ADR-0001.md)）。它和準確率可以反向移動。
2. **切分**：`train`／`val_select`（選檢查點）／`val_assess`（評估，從不參與選擇）。**沒有封存測試集**（[E40](實驗/E40.md)）：報告裡的 `sealed_test_used: false` 只是協定標記。`val_assess` 被讀過很多次，所以它的結果屬於「內部確認」。
3. **manifest 不同，數字不能直接比**。2026-11-12 起所有訓練改用排除 ISIC 各屆挑戰賽官方測試集的 manifest（[E123](實驗/E123.md)，俗稱 HC）；在那之前的數字量在舊 manifest 上。
4. **雜訊**：同設定不同 seed 的最差來源差異約 0.65–1.78pp（[E44](實驗/E44.md)）；早期估的噪音帶 1.68–3.69pp（[E18](實驗/E18.md)、[E21](實驗/E21.md)）。小於這個量級的差異多半判不出來。
5. 很多實驗是**單一 seed、20 epoch 短跑**；正式結論要長跑（60 epoch）與多 seed 確認。

## 研究對象

四個來源的皮膚病灶影像：BCN20000、HAM10000、ISIC_Archive_Expanded、PAD-UFES-20（PAD 是手機臨床照，其餘是皮膚鏡）。
八類：AKIEC、BCC、BKL、DF、NV、VASC、MEL、SCC。目標是一個至少八類、而且在「最差的來源」上也站得住的分類器。

## 目前狀態（2026-11-17）

- **現行基準模型**：R2-REG-LONG-HC（convnext_small@384、mixup＋random erasing、60 epoch，HC manifest）。最終 val_select 最差來源 0.6823、val_assess 最差來源 0.6841（[E123](實驗/E123.md)）。
- **對照醫師**：在留出的 ISIC 2018 Task 3 測試集上，7 類平均敏感度 0.776（文獻中專家 0.812、全體讀者 0.792，皆為群體多數決）；平衡題組每 30 題答對 23.28（單一醫師平均 17.91、專家 18.78）；惡性 AUC 0.916（讀者投票 0.958）；AKIEC 0.465（專家 0.512）（[E124](實驗/E124.md)）。
- **舊 manifest 的最佳單一模型** R2-REG-LONG 的 val_assess 0.6819，扣除 148 張「訓練集裡有同一張圖」的評估影像後下修為 0.6728（[E91](實驗/E91.md)、[E100b](實驗/E100b.md)）。
- **減法實驗 [E139](實驗/E139.md) 已結束**：最終只拿掉 mixup、random erasing、label smoothing（20 epoch 短跑結論）。
- **進行中**：GPU 佇列依序還有 P003（模型瘦身）、P005（MaxViT-T）、P007（色彩恆常化）、P011（下一代 manifest）、P014（多 seed 確認）、P018（K-means 錯誤分群）。

## 主要發現

**1. 主要問題是「系統性錯誤」，不是過擬合。**
多個模型在同一批影像上一起錯（val_assess 上六個模型全錯 760 張，虛無預期 0.5 張），佔 R2 錯誤的 43.1%（[E17](實驗/E17.md)、[ADR-0004](實驗/ADR-0004.md)）。正則化（mixup＋erasing）只修掉其中 42 張（[E18](實驗/E18.md)）；換成 Swin 也只修掉 8.0%（[E80](實驗/E80.md)）。這些難例成群出現（約 480 個獨立難例，而非 699 張，[E85b](實驗/E85b.md)），在影像統計量上看不出是「壞影像」（[E86](實驗/E86.md)）。已排除的解釋見 [ADR-0005](實驗/ADR-0005.md)。

**2. 唯一區間不含 0 的槓桿是集成。**
九個模型等權平均在舊 manifest 的 val_assess 達 0.6890，對 R2 +3.49pp（95% CI +1.12～+5.66）（[ADR-0007](實驗/ADR-0007.md)、[E36](實驗/E36.md)）。兩個模型就拿到 +2.97pp（[E36b](實驗/E36b.md)）；36 個配對中 32 個贏過 R2（[E36c](實驗/E36c.md)）。但集成在共錯影像上只修對 1 張——它能「避開」（配合棄答）但「修不了」系統性錯誤（[E38](實驗/E38.md)）。

**3. 換架構、換頭、加長訓練，都沒有可辨識的效果。**
- Swin 對 ConvNeXt：方向相反且在噪音內（[E81](實驗/E81.md)）；改 224 反而更差（[E89](實驗/E89.md)）。
- 一對多專家／MoE：依事先登記判定不值得做（[E30](實驗/E30.md)）；共享骨幹階梯是死路（[E44](實驗/E44.md)）。
- KAN 分類頭：−1.34pp，在噪音帶內（[E108](實驗/E108.md)）。
- 60 epoch 長跑對 20 epoch：+0.32pp，在噪音帶內（[E91](實驗/E91.md)）。
- ImageNet-22k 預訓練：短跑 0.6395，低於基準 0.6715（[E127](實驗/E127.md)、[E132](實驗/E132.md)）。
- 例外：解析度有用。同骨幹 224→384 +2.74pp（[E102](實驗/E102.md)）。

**4. 偵測裁切沒有用。** k=1.5 與 k=1.0 都在噪音內，PAD 隨 k 變小惡化（[E56](實驗/E56.md)、[E60](實驗/E60.md)）；PAD 的退步也不是醫師墨圈造成的（[E59](實驗/E59.md)、[E59b](實驗/E59b.md)）。

**5. 跨來源泛化：皮膚鏡之間幾乎不掉，皮膚鏡到手機照掉很多。**
訓練時拿掉 BCN，BCN 上 −0.05pp（CI 跨 0，[E96](實驗/E96.md)）；拿掉 PAD，PAD 上 −17.97pp（CI −24.63～−11.60，[E96b](實驗/E96b.md)）。凍結的 ImageNet 特徵就能以 0.8542 的平衡準確率認出影像來源（[P0](實驗/P0.md)）。低頻頻譜互換（FDA）對 PAD 兩個 seed 方向一致為正，但和隨機外框同開時好處消失（[E132](實驗/E132.md)、[E133](實驗/E133.md)）。

**6. 資料本身的問題比預期多。**
- 1,682 對重新編碼的重複影像、25 對同圖不同標籤，148 張 val_assess 在 train 裡有同一張圖（[E100b](實驗/E100b.md)）。
- 68 張純白影像（64 張在 val_assess），已排除（[E88](實驗/E88.md)、[E90](實驗/E90.md)）。
- ISIC 各屆挑戰賽官方測試集原本混在訓練資料裡，2026-11-12 起排除（[E120](實驗/E120.md)、[E123](實驗/E123.md)）。
- 前處理把 ISIC 壓到只剩 7.48% 像素、大多數非方形影像被壓扁（[E102](實驗/E102.md)、[E143](實驗/E143.md)）；只在推論端改成不壓扁並不能改善（[E142](實驗/E142.md)）。

**7. 類別平衡抽樣要保留；mixup、erasing、label smoothing 這組在短跑可以拿掉。**
取樣器讓 NV 從檔案的 57.24% 壓到實際 15.27%（[ADR-0002](實驗/ADR-0002.md)、[E20](實驗/E20.md)）。減法實驗中拿掉類別平衡抽樣不通過，拿掉 mixup＋erasing＋label smoothing 通過；ColorJitter 與逐層衰減各自拿掉都通過、一起拿掉卻不通過，所以保留（[E139](實驗/E139.md)，限 20 epoch 短跑）。

**8. 選模指標有代價。** 用「最差來源」選模，比起整體表現，代價約 3.5pp 的整體平衡準確率（[E116](實驗/E116.md)）。

## 推翻與更正

這個專題的紀錄保留了大量「後來發現錯了」的過程，每頁的「推論」段都會寫出。較重要的幾個：
- 「問題是過擬合、正則化對症」→ 被 [E17](實驗/E17.md)／[E18](實驗/E18.md)／[ADR-0004](實驗/ADR-0004.md) 推翻。
- 「資料無洩漏、無重複」（[E19](實驗/E19.md)、[E21](實驗/E21.md)）→ [E100b](實驗/E100b.md) 找到重複與評估污染。
- 「模型靠尺規捷徑」（[E94](實驗/E94.md) 第一版）→ 前處理寫錯而撤回，[E104](實驗/E104.md) 遮罩介入否證。
- 「空間頭定位失敗」（[A1](實驗/A1.md)）→ [A2](實驗/A2.md) 證明是讀出方式錯誤。
- R0 存檔 logits 對不上的原因（[E42](實驗/E42.md)）→ [E45](實驗/E45.md) 查出是未提交的 `Image.draft` 前處理最佳化。
- 共用 softmax 的判決讀在錯的切分上（[E37](實驗/E37.md)）→ [E44](實驗/E44.md) 更正。

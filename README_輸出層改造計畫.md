## 1. 問題陳述

目前系統接收一張影像，輸出七類的 softmax 機率與 Grad-CAM。這個輸出有三個問題：

**1.1 沒有「不知道」這個選項**

封閉集合分類器會把任何輸入分到七類之一。一張手部照片、一張模糊照、一種訓練資料裡沒有的皮膚病，都會得到一個高機率的答案。使用者無從分辨「模型很確定」和「模型被迫猜一個」。

**1.2 機率分布過度自信**

章節 06 的 ECE 是 9.79%，混合訓練版的 BCN 更高到 18.13%。模型說 90% 的時候，實際正確率沒有 90%。這就是「輸出不平滑」的字面意義——分布太尖。

**1.3 用單一 argmax 回答一個本質上有不確定性的問題**

皮膚影像經常對應多個相似疾病。只給一個類別，等於把模型內部的猶豫全部丟掉。

---

## 2. 關鍵診斷：粗粒度輸出救不了

一個直覺的想法是「既然七類太細，就先回答良性／惡性」。**這個方向經過量測，不成立。**

以章節 06 三個 seed 的混淆矩陣重新分群：

| 輸出粒度 | BA | Accuracy | 備註 |
|---|---|---|---|
| 七類（現況） | 77.50% | 85.75% | |
| 三群：惡性／癌前／良性 | 78.19%（s=1.66） | 89.16% | 惡性 recall 67.6% |
| 二分：惡性 vs 其他 | 81.18% | — | 敏感度 67.6%、特異度 94.74% |

**BA 只從 77.5 移動到 78.2。** 原因在錯誤的結構。三 seed 加總後最大的五組混淆：

| 實際 | 判成 | 張數 | 是否跨良惡邊界 |
|---|---|---|---|
| MEL | NV | 161 | **是** |
| NV | MEL | 106 | **是** |
| BKL | NV | 63 | 否 |
| NV | BKL | 57 | 否 |
| BKL | MEL | 35 | **是** |

主要錯誤正好落在良性與惡性的交界上，任何分群方式都吸收不掉。

**真正的數字是惡性敏感度 67.6%**——每三個黑色素瘤或基底細胞癌漏掉一個，同時特異度有 94.74%。這個組合代表模型的決策閾值偏向「不要誤報」，而臨床上的代價是相反的。

**結論**：改進方向不是換粒度，是三件事——**把信心校準、把閾值調到正確的代價方向、把不確定性顯示出來**。

---

## 3. 為什麼不增加類別數

**不新增資料集的前提下，類別數無法增加。** 目前七類來自 HAM10000 的標籤體系，第八類 SCC 來自治理 v2 已下載的來源。所有已標註的資料都已經用上。

有一個理論上的選項：manifest 保留了原始診斷字串，而 BKL 和 AKIEC 本身是家族標籤（BKL 含脂漏性角化症、日光性小痣、扁平苔癬樣角化症）。技術上可以拆細。

**但不建議。** 現在最弱的類別是樣本最少的那幾類——DF 759 張、VASC 645 張。把 BKL 拆成三個子類只會製造三個更小的類別，而稀有類別正是目前的瓶頸。拆細會讓 BA 下降而不是上升。

這點值得在報告裡明講：**類別數不是我們選擇的設計，是可用標註的上限。**

## 4. 工作項目

全部不需要重新訓練骨幹，使用既有的三個 seed checkpoint。按依賴順序排列。

### O0　基線重算（必須先做）

目前的 `result.json` 只存了彙總指標與混淆矩陣，沒有逐樣本的機率。後面所有工作都需要原始輸出。

- 對三個 seed 的 checkpoint 在 validation 上跑推論
- 存下每一張的 **logits、softmax 機率、真實標籤、來源、影像 ID**
- 存成 `輸出層改造/results/O0_predictions_seed{17,42,2026}.csv`
- 驗收：用這份輸出重算 BA、Macro-F1、ECE，必須與既有 `result.json` 的數字一致（容許浮點誤差）

**閘門 G-O0**：若重算的 BA 與原記錄差異超過 0.1 個百分點，停止並查明原因——代表推論管線與訓練時不一致。

### O1　溫度校正

- 在 validation 上擬合單一溫度 T，最小化 NLL
- 逐來源分別擬合一次，與全域共用一個 T 做比較
- 報告校正前後的 ECE 與可靠度圖

**閘門 G-O1**：ECE 下降且 BA 不退步（差值小於 seed 標準差）才採用。溫度校正理論上不改變 argmax，所以 BA 應該完全不動；若動了，代表實作有誤。

### O2　代價敏感的決策閾值

目前是 argmax。改成最小化期望代價：

```
預測 = argmin_c  Σ_k  P(k) × Cost(k → c)
```

- 先用對稱代價驗證能重現 argmax 的結果
- 再定義不對稱代價矩陣：漏判惡性的代價遠高於誤報
- 掃描代價比例，畫出**敏感度–特異度曲線**，標出目前的 (67.6%, 94.74%) 位置

**這一項預期效益最大。** 目前特異度 94.74% 有很大的讓步空間，用特異度換敏感度是直接的交易。

**閘門 G-O2**：在特異度不低於 85% 的條件下，惡性敏感度必須提升至少 5 個百分點，且三個 seed 方向一致。

> 代價矩陣的數值需要有依據。建議請教指導教授，或引用文獻中的切片決策門檻，不要自己設一組數字。

### O3　多候選與不確定性顯示

- 計算 Top-2、Top-3 accuracy
- UI 從「單一答案」改成「最可能的 2–3 個候選 + 機率」
- 當前兩名的機率差小於門檻時，明確顯示「模型無法區分這兩者」

**閘門 G-O3**：Top-2 accuracy 必須明顯高於 Top-1，否則顯示多候選沒有意義。

### O4　分布外拒答

不需要額外資料集的三種做法，全部只用現有的訓練集與模型：

| 方法 | 需要什麼 | 成本 |
|---|---|---|
| Maximum Softmax Probability | 只要機率 | 零 |
| Energy score | 只要 logits | 零 |
| Mahalanobis 距離 | 訓練集的倒數第二層特徵統計量 | 跑一次訓練集推論 |

- 用驗證集內「模型答錯且信心低」的樣本當作代理的困難樣本
- 畫 **risk–coverage 曲線**：覆蓋率 80%／60%／40% 時的錯誤率
- 低於門檻時輸出「信心不足，建議就醫」而非強行分類

**閘門 G-O4**：在覆蓋率 80% 時，錯誤率必須明顯低於全覆蓋的錯誤率。

> 限制必須寫清楚：沒有真正的 OOD 資料集，所以這一項只能證明「拒答機制能篩掉模型自己不確定的樣本」，不能證明「能擋掉非皮膚影像」。後者需要新資料，不在本計畫範圍。

### O5　三 seed 集成

三個 seed 的權重已經存在，平均 softmax 即可。

**閘門 G-O5**：BA 提升必須大於單一 seed 的樣本標準差（治理版是 1.94）才採用。

> 集成會讓推論成本變三倍。若效益小於門檻，就不採用，並把這個負結果記錄下來。

## 5. 明確不做的事

| 不做 | 理由 |
|---|---|
| 新增資料集 | 本計畫的前提約束 |
| 重新訓練骨幹 | 同上；八分類重訓是另一條獨立軌道 |
| 增加類別數 | 可用標註已用盡，見 §3 |
| 拆細 BKL／AKIEC 子類 | 會製造更多稀有類別，加重現有瓶頸 |
| 開封測試集 | 全部工作在 validation 上完成 |
| 階層式輸出 | 已量測，效益不足，見 §2 |

## 6. 評估協定

- 全部在 validation 上進行，測試集維持封存
- 所有結果報告三個 seed 的平均與樣本標準差
- 沿用既有納入規則：**提升幅度小於樣本標準差者不採納**
- 逐來源分別報告（HAM／BCN／PAD），不只看平均
- 每一項都必須同時報告惡性敏感度與特異度，不能只報 BA

**主要指標改為惡性敏感度**（在固定特異度下），因為本計畫的目標是輸出的可用性，不是分類分數。BA 降為輔助指標。

---

## 7. 風險

**代價矩陣沒有依據。** 不對稱代價的數值如果是自己拍的，整個 O2 的結論就沒有說服力。這是本計畫最大的風險，必須先解決依據問題再動手。

**驗證集被重複使用。** O1 到 O5 全部在同一份 validation 上調參，有過擬合驗證集的風險。緩解方式是把 validation 再切一半，一半調參、一半評估；或接受這個限制並在報告中寫明。

**拒答機制無法驗證真正的 OOD。** 見 O4 的限制說明。

**集成與多候選會增加 UI 複雜度。** 使用者看到三個候選加一個「信心不足」的狀態，可能比單一答案更難理解。需要在介面設計上處理，不是純技術問題。

---

## 8. 與既有軌道的關係

本計畫**不影響**也**不等待**八分類重訓那條軌道。所有產出（溫度、閾值、拒答門檻、集成方式）都是在既有 checkpoint 上建立的方法，等八分類模型訓練完成後，同一套流程可以直接重跑一次。

兩條軌道的關係：

```
軌道 A（既有）：治理 v2 八分類資料 → 擴充分類器 → 重新訓練
軌道 B（本計畫）：既有 checkpoint → 輸出層改造 → 方法確立
            ↓
      A 完成後，B 的方法套用到 A 的新模型
```

先做 B 的理由：成本低、不需要算力、而且 B 的產出（特別是代價敏感閾值）會告訴你 A 應該用什麼指標選模。
